## Context
这次要把个人网站从“按历史路径展示的笔记集合”升级为“可长期维护的技术知识库”，不是再做一轮目录换名。当前使用 VitePress，已有六大分类的数据源，但正文仍分散在 `AI/面试/`、`interview/` 等历史目录；分类页主要是长列表，缺少独立专题入口、学习路线与知识关系。

已确认：现有 **265 个 Markdown 文件（不含现有生成的分类页）**，还有图片、JavaScript/TypeScript 练习、HTML 示例等。工作区存在未提交修改与新增文章，本次以当前工作区为基线，保留这些工作，不覆盖或回退。网站保持原有粉色、衬线标题、搜索、明暗主题、动效和阅读布局。

## 推荐实施方案

### 1. 先建立完整保留基线与迁移清单
- 盘点全部文章、代码示例和引用资源，不只统计当前侧边栏中的文章；补收 `mcpServer工具如何变成agentTool.md`、学习路线、各语言概览、历史技术方案等漏收内容。
- 为每个已有文档记录旧路径、新路径、中文标题、英文 slug、所属专题、文档类型与原内容校验信息。
- 保留原有段落、代码块、表格、图示和刷题进度。仅改变组织方式、元数据和必要的链接，不进行删减式改写。
- 同题的详细版、简记版、口述版不直接删除：确定主文档，其他版本作为补充笔记或面试材料关联，避免误把不同内容当重复内容丢掉。

### 2. 实际迁移到六大领域，而不只改变导航显示
采用你给出的文件树，英文小写目录与 kebab-case slug，中文标题保留：
- `docs/frontend/`：HTML、CSS、JavaScript、TypeScript、浏览器、Web 网络、Vue、性能与业务实践。
- `docs/ai/`：大模型、提示词工程、RAG，以及 `agent/{architecture,multi-agent,harness,mcp,extensions,ecosystem}`。
- `docs/engineering/`：架构、Node.js、服务端框架、全栈框架、工程化及工程实践。
- `docs/computer-science/`：网络基础与算法；没有内容的操作系统目录不制造文章。
- `docs/interview/`：前端、AI、系统设计、算法及题库/复盘。
- `docs/tools/`：Git、Shell、调试和开发工具。

归类规则：
- 浏览器渲染模式进入浏览器；流式打字机进入前端实践。
- Map 与 Redis 已核实是会话存储方案比较，归工程架构，而不是 JS Map API。
- TCP/UDP 等底层网络知识有唯一主归属，前端网络通过关联入口引用。
- 面试目录主要提供问题组织与回链；技术原理不复制一份。现有真实的口述稿、项目回答、刷题进度保留在面试体系。
- 代码练习、示例和既有方案记录也保留，并提供可发现的入口。

### 3. 建立真正的专题入口与知识关联
- 一级、已有内容的二级，以及 Agent 等必要三级专题建立 `index.md`。
- 入口包含：专题职责、先修知识、推荐学习顺序、核心文章、关联实践、面试入口和扩展方向；不再仅生成整站式长列表。
- AI 主线明确为：模型与 Prompt → RAG → Agent 架构 → Harness 执行环境 → MCP 工具连接 → Skill/Rule/Prompt 扩展 → 多 Agent 与产品实现。
- 为 MCP、Harness 等增加知识关系/执行链路图，引用并保留现有正文中的架构图与源码分析。
- 没有独立文章的概念，通过相关原文或原文小节链接介绍，不为“填满目录”生成伪文章。

### 4. 升级统一导航和阅读上下文
复用 `docs/.vitepress/navigation.ts` 中现有的 `noteCategories`、`topicLink`、侧边栏生成逻辑，以及 `HomeTopics.vue` 的首页目录样式。
- 首页、顶栏、领域入口、侧边栏继续共用一份目录数据。
- 顶栏显示六大领域，首页入口改指向新领域路径。
- 左侧按当前领域展示二级/三级专题，避免每篇文章都展开整个站点目录；右侧保留文章 TOC。
- 阅读页增加轻量的知识归属/专题回链，让面试题能返回知识主文档，补充笔记能返回主专题。
- 保留现有搜索与侧边栏收起功能，适配窄屏和减少动态效果偏好。

### 5. 兼容旧网址，并统一维护规范
- 迁移正文中的站内文章链接、相对图片路径和示例引用。
- 为旧文章网址与 `/catalog/...` 入口生成静态兼容页，跳转到唯一新地址，保留 URL hash；兼容页不进入搜索索引，不复制原文。
- 增加文章 Frontmatter 的合理默认字段：`title`、`description`、`tags`、文档类型等；已有字段保留，日期不伪造历史更新信息。
- 建立概念、架构、源码分析、对比、面试模板及维护说明；模板不作为正式知识文章发布。
- 更新 `scripts/README.md` 与目录校验脚本，明确新增文章和生成专题入口的方法。
