## Context
当前 VitePress 笔记站的首页、顶部导航和侧边栏分别维护不同目录，工程、AI、算法等文章也混在历史目录中。这次按你给出的六大分类统一信息结构，保留个人学习、查阅和面试复习用途，以及现有粉色风格、阅读布局、搜索与动效。

## 实施方案
1. **统一目录数据**
   - 新增 `docs/.vitepress/navigation.ts`，集中维护「前端开发 / AI 与 Agent / 工程与架构 / 计算机基础 / 面试与题库 / 工具与实践」及你给出的子分类。
   - 复用现有文章链接与已有 CSS、JavaScript、Vue 等细分分组；将 Node.js、构建工程、架构、工具、计算机基础移到对应大类。
   - 纳入已有但缺少入口的文章（如 MCP 平台自研方案），保留当前未提交的 DeepSeek Harness 入口。
   - 学习文章按主题归类，题库用专题索引与交叉链接组织，不把所有 `interview` 路径的文章误当成面试题。
2. **首页与分类页**
   - 修改 `docs/index.md` 和 `docs/.vitepress/theme/components/HomeTopics.vue`：首页展示六大分类，更新介绍与阅读入口。
   - 新增六个分类总览页及必要的专题索引，呈现完整层级并链接现有内容。没有文章的分类明确标注“待补充”，不伪造内容。
   - 保留现有字体、粉色配色和目录列表样式，补充必要的层级、移动端与键盘焦点样式。
3. **导航与侧边栏同步**
   - 修改 `docs/.vitepress/config.mts`，顶部展示六大分类入口，首页和侧边栏从同一份目录数据生成。
   - 采用六大分类的统一可折叠侧边栏，并复用 VitePress 当前文章展开、高亮和现有 `Layout.vue` 的定位、收起功能。
   - **不移动或重命名现有文章文件**，旧网址和文章内链接保持可用；不修改无关的图片删除和用户配置文件。
4. **维护说明与回归检查**
   - 记录已确认的设计上下文，并补充目录维护说明、自动校验脚本，检查分类层级、所有导航目标、旧入口覆盖和重复项。
   - 若实际构建仍被已存在的 Vue 文档插值示例阻塞，仅修正该示例的代码围栏，避免改变文章含义。
