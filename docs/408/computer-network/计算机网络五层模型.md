# 计算机网络五层模型

- 应用层：负责应用程序之间的业务交互逻辑与数据格式标准
- 传输层：负责端到端的通信。
- 网络层：负责最佳路径选择（路由）与 IP 逻辑寻址
- 数据链路层： 同一局域网内相邻节点（设备）间的帧传输与 MAC 硬件寻址
- 物理层：物理传输介质上原始比特流（0 和 1）的传输与信号转换

- 总：
  - 发送消息时，消息从上到下进行打包，接收时，消息从下到上进行解包。
- 分：

  - 应用层主要面向**互联网的应用场景**，比如网页、邮件、文件中心等。代表协议有 http、smtp、ftp、POP3、DNS 等。

  - 传输层主要面向**端到端的通信**，比如 TCP 协议为了保证可靠传输，UDP 则是一种无连接的广播。

  - 网络层解决**如何定位目标以及如何寻找最优路径的问题**，比如 IP 协议。

  - 数据链路层解决**数据在一个子网（广播域/局域网）内有效传输**，MAC 地址、交换机都属于该层。

  - 物理层解决设备的电气信号传输问题，比如网线、光纤等。

## OSI 七层模型

- 应用层
- 表示层
- 会话层
- 传输层
- 网络层
- 数据链路层
- 物理层

## TCP/IP 四层模型

- 应用层
- 传输层
- 网际层
- 数据链路层
