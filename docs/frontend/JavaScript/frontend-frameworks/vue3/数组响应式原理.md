# Vue 数组响应式原理

## Vue 2

### 核心限制

`Object.defineProperty` 无法原生检测以下数组变动：

1. 利用索引直接设置一个项时，例如：`vm.items[indexOfItem] = newValue`
2. 修改数组的长度时，例如：`vm.items.length = newLength`

### 解决方案

Vue 2 通过**重写（Monkey Patch）**数组的原型方法来实现响应式。

1. **拦截变异方法**：
   Vue 拦截了数组的 7 个变异方法（Mutation Methods）：

   - `push()`
   - `pop()`
   - `shift()`
   - `unshift()`
   - `splice()`
   - `sort()`
   - `reverse()`

2. **具体实现逻辑**：
   - 创建一个继承自 `Array.prototype` 的新对象 `arrayMethods`。
   - 在 `arrayMethods` 上定义上述 7 个方法。
   - 当调用这些方法时：
     - 执行原生的数组方法。
     - 获取 `Observer` 实例 (`__ob__`)。
     - 如果是插入操作（`push`, `unshift`, `splice`），会调用 `observeArray` 对新插入的元素进行响应式处理。
     - 最后调用 `ob.dep.notify()` 手动触发依赖更新。

## Vue 3

### 核心机制

Vue 3 使用 **Proxy** 替代了 `Object.defineProperty`。

### 优势

- **全方位拦截**：`Proxy` 可以拦截对象和数组的几乎所有操作，包括索引赋值 (`arr[0] = 1`) 和 length 修改 (`arr.length = 0`)。
- **无需重写原型**：不再需要 Hack 数组的原型方法，而是直接拦截 `get` 和 `set` 操作。

### 实现细节

- **Get 拦截**：访问数组元素时，收集依赖 (`track`)。
- **Set 拦截**：修改数组元素或 `length` 时，触发更新 (`trigger`)。
- **特殊处理**：
  - 虽然 Proxy 强大，但 Vue 3 内部依然对 `includes`, `indexOf`, `lastIndexOf` 等读取方法进行了简单的包装，以确保在响应式数组中查找原始对象时也能正确工作（Ref 自动解包等边缘情况）。
  - 对 `push`, `pop` 等会修改 `length` 的方法也做了微调，以避免在某些副作用（如 `watchEffect`）中导致无限循环。
