# ==和===的区别

## == 等值比较

- 原理：在比较前，如果两边的类型不同，浏览器会先进行 **隐式类型转换**，将其转为相同的类型后再进行比较。

- 特点：比较的是“值”是否相等，不关心类型。

## === 全等比较

- 原理：**直接比较**。如果类型不同，直接返回 false；如果类型相同，再比较值是否相等。

- 特点：**不进行类型转换**。
