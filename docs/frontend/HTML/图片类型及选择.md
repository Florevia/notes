**前端图片知识点整理**

**一、两大类**
- **位图**：由一个个像素点组成，放大会糊，照片都属于这一类。
- **矢量图**：用数学公式描述线条和形状，怎么放大都清晰，适合图标和 Logo。

**二、常见格式**
- **JPG / JPEG**：有损压缩，适合照片，文件小；不支持透明，反复保存会越来越糊。
- **PNG**：无损压缩，支持透明，适合图标、截图和带文字的图；存照片体积很大。
- **GIF**：最多 256 色，支持简单动画，画质和体积都已经落后了。
- **WebP**：Google 推出，有损、无损、透明、动画都支持，同等画质通常比 JPG 和 PNG 小 25% 到 35%。
- **AVIF**：更新的格式，压缩率比 WebP 还高；缺点是编码慢，老设备可能不支持。
- **SVG**：矢量图，本质是一段 XML 代码，能用 CSS 改颜色、做动画，任何屏幕都清晰。
- **ICO**：网站标签页上的小图标（favicon）。
- **HEIC**：iPhone 拍照的默认格式，浏览器基本不支持，上传网页前要转格式。

**三、怎么选**

先想清楚三件事：图是什么内容、需不需要透明、要不要动。
1. **图标、Logo、简单图形**：首选 SVG。
2. **照片、Banner、商品图**：首选 AVIF 或 WebP，用 JPG 兜底。
3. **需要透明的图**：WebP 或 AVIF，用 PNG 兜底。
4. **截图、文字多的图**：PNG 或无损 WebP，避免 JPG 把文字边缘压出毛刺。
5. **动画**：短的用 WebP 或 AVIF 动图，长的用 `<video>` 播 MP4 或 WebM；UI 动效用 CSS、SVG 或 Lottie。

**四、兼容写法**

用 `<picture>` 让浏览器自己挑它支持的最好格式：
```html
<picture>
  <source srcset="hero.avif" type="image/avif">
  <source srcset="hero.webp" type="image/webp">
  <img src="hero.jpg" alt="首页横幅" width="1200" height="600" loading="lazy">
</picture>
```

**五、为什么要兜底**

因为不是所有浏览器和设备都认新格式。浏览器会从上往下挑：支持 AVIF 就用 AVIF，不支持就试 WebP，都不行就用最后 `<img>` 里的 JPG 或 PNG。没有这一层，老环境就会显示裂图。
- **现代 Chrome、Edge、Safari、Firefox**：都支持，会直接用新格式。
- **旧版 Safari（大约 iOS 16 以前）、老安卓、部分国产浏览器内核**：可能不认 AVIF，甚至不认 WebP。
- **邮件客户端、部分版本的微信内置浏览器、打印预览、某些爬虫**：支持不稳定。

兜底不是因为新格式不好，而是给少数不认识它的环境留一条退路。内部系统确定都是新浏览器的话，可以只用 WebP 或 AVIF；面向公众的网站还是留一层 JPG 或 PNG 更稳妥。

**六、格式之外同样重要的事**
- **尺寸合适**：别把 4000 像素的原图塞进 300 像素的位置。用 `srcset` 和 `sizes` 给不同屏幕提供不同大小，高清屏准备 2 倍图。
- **压缩**：用 Squoosh、TinyPNG，或者在构建时用 `sharp` 这类工具自动压缩。
- **懒加载**：屏幕外的图片加 `loading="lazy"`；首屏大图不要懒加载，可以加 `fetchpriority="high"`。
- **写明宽高**：给 `<img>` 设 `width` 和 `height`，避免加载时页面跳动。
- **交给框架或 CDN**：Next.js 的 `<Image>` 组件、Cloudinary、阿里云 OSS 这类图片服务，能自动转成 WebP 或 AVIF 并按需裁剪。

**一句话总结**：图标用 SVG，照片用 AVIF 或 WebP 加 JPG 兜底，透明图用 WebP 加 PNG 兜底，动画尽量用视频，最后控制好尺寸和压缩。
