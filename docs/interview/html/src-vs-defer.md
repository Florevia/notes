# src 和 defer (script 标签属性)

在 HTML 中引入外部 JS 文件时，`script` 标签的执行时机对页面渲染性能有重要影响。

## 默认行为 (`<script src="...">`)

- **解析中断**: 浏览器遇到 script 标签会暂停 HTML 解析。
- **立即下载并执行**: 下载和执行脚本都会阻塞文档解析。

## `async` (`<script async src="...">`)

- **异步下载**: 脚本下载与 HTML 解析并行进行。
- **下载完立即执行**: 下载完成后立即暂停 HTML 解析并执行脚本。
- **执行顺序不确定**: 多个 async 脚本谁先下载完谁先执行，不保证顺序。
- **适用场景**: 独立的脚本，如统计代码，不依赖 DOM 或其他脚本。

## `defer` (`<script defer src="...">`)

- **异步下载**: 脚本下载与 HTML 解析并行进行。
- **延迟执行**: 脚本会在 HTML 解析完成（`DOMContentLoaded` 之前）后才执行。
- **按顺序执行**: 多个 defer 脚本会按照在 HTML 中出现的顺序执行。
- **适用场景**: 依赖 DOM 或相互依赖的脚本，推荐默认使用。

## 总结图示

| 模式    | 下载 | 执行时机   | 阻塞解析    | 如果依赖 DOM        | 如果相互依赖 |
| :------ | :--- | :--------- | :---------- | :------------------ | :----------- |
| Default | 阻塞 | 立即       | 是          | 不行 (除非放在底部) | 可以         |
| async   | 并行 | 下载完立即 | 是 (执行时) | 不行                | 不行         |
| defer   | 并行 | 解析完后   | 否          | 可以                | 可以         |
