# iframe

`<iframe>`（Inline Frame）是 HTML 标签，用于在当前的 HTML 文档中嵌入另一个独立的 HTML 文档。它创建了一个包含另一个文档的行内框架。

## 优点与缺点

### 优点

- 资源隔离 (Sandboxing)： Iframe 内部的 CSS、JavaScript 变量与主页面是隔离的，不会产生全局污染（除非显式通信）。

- 加载第三方内容便捷： 能够极其方便地引入广告、视频（如 YouTube）、地图（Google Maps）等第三方内容，无需复杂的 API 集成。

- 安全控制： 也就是 sandbox 属性，可以限制 Iframe 内内容的权限（如禁止脚本执行、禁止表单提交等）。

- 并行加载： 浏览器对同域名的连接数有限制，Iframe 的脚本和 CSS 加载可以利用浏览器的多线程，不占用主页面的加载线程（但会阻塞 onload，需注意）。

### 缺点

- 性能开销大： 每个 Iframe 都是一个完整的浏览器上下文，需要独立的内存和 CPU 资源来渲染。

- 阻塞主页面 Onload： Iframe 的加载会阻塞主页面的 window.onload 事件触发，影响用户感知的加载速度（可通过动态 JS 创建 Iframe 解决）。

- SEO 不友好： 搜索引擎爬虫通常难以索引 Iframe 内部的内容。

- 交互与通信困难： 跨域通信需要使用 postMessage，调试复杂；且 Iframe 内部的滚动条、弹窗往往难以与主页面 UI 完美融合（“画中画”的割裂感）。

- 安全风险： 容易遭受 **点击劫持 (Clickjacking) 攻击**。

## 使用场景

1. 加载第三方媒体/组件： 视频播放器、在线地图、第三方登录框。

2. 广告嵌入： 广告商通常使用 Iframe 投放广告，以确保广告脚本不破坏主站代码，同时保证安全。

3. 代码沙箱： 在线编辑器为了防止用户代码破坏编辑器本身，会将运行结果放在 Iframe 中。
