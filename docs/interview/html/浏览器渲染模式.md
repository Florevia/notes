# 浏览器渲染模式

浏览器的渲染模式决定了浏览器如何解析 CSS 和排版 HTML。主要分为三种模式：

- **标准模式 (Standards Mode)**。
- **怪异模式 (Quirks Mode)**。
- **几乎标准模式 (Almost Standards Mode)**。

## 1. 为什么会有多种模式？（历史背景）

在互联网早期（IE5/IE6 时代），W3C 标准还没完全统一，浏览器厂商（主要是 Microsoft）按照自己的方式实现渲染，这被称为“**怪异模式**”。

后来，W3C 标准确立了。为了不破坏旧有的、不符合标准的网站（想容旧），浏览器引入了新的**标准模式**。

- 如果网页声明了符合标准的 `DOCTYPE`，浏览器就用**标准模式**渲染。
- 如果网页没有声明 `DOCTYPE` 或者声明有误，浏览器就认为这是个老网页，切换到**怪异模式**，模仿老 IE 的行为。

## 2. 模式介绍

### A. 标准模式 (Standards Mode)

- **触发条件**：文件顶部有完整的、符合标准的 `<!DOCTYPE html>` 声明。
- **行为**：浏览器严格按照 W3C 标准解析代码。
- **现状**：现代开发中，**必须**使用此模式。

### B. 怪异模式 (Quirks Mode)

- **触发条件**：
  - 没写 `DOCTYPE`。
  - `DOCTYPE` 写错了。
  - `DOCTYPE` 之前有其他字符（现在的浏览器比较宽容，空格可能没事，但以前会有问题）。
- **行为**：浏览器模拟老式浏览器（如 IE5）的行为。
- **主要区别**：
  - **盒模型 (Box Model)**：
    - 标准模式：`width` = 内容宽度 (content)。
    - 怪异模式：`width` = 内容 + padding + border (即 `border-box`)。
  - **图片垂直对齐**：表格内的图片垂直对齐方式不同。
  - **内联元素尺寸**：怪异模式下，给行内元素 (inline) 设置宽高可能生效，标准模式下无效。

### C. 几乎标准模式 (Almost Standards Mode)

- **触发条件**：使用了一些过渡期的 DOCTYPE（如 HTML 4.01 Transitional）。
- **行为**：除了**表格单元格内的图片垂直布局**和标准模式略有不同外，其他行为和标准模式完全一致。现代开发很少涉及。

## 3. 常见差异对比

| 特性               | 标准模式 (Standards Mode)                           | 怪异模式 (Quirks Mode)                                                |
| :----------------- | :-------------------------------------------------- | :-------------------------------------------------------------------- |
| **盒模型**         | `box-sizing: content-box` (默认)<br>width = content | `box-sizing: border-box` (默认)<br>width = content + padding + border |
| **行内元素宽高**   | 给 `<span>` 等行内元素设 width/height **无效**      | 可能**生效**                                                          |
| **margin: 0 auto** | 元素水平居中**生效**                                | **失效** (旧版 IE)                                                    |
| **百分比高度**     | 如果父元素没设高度，子元素 `height: 100%` 通常无效  | 常常会按视口或父元素自动生效                                          |

## 4. 如何查看当前模式？

在控制台 (Console) 输入：

```javascript
document.compatMode;
```

- 输出 `CSS1Compat`：**标准模式** (Standards Mode)。
- 输出 `BackCompat`：**怪异模式** (Quirks Mode)。

## 5. 最佳实践

在所有 HTML 文件的第一行，永远加上：

```html
<!DOCTYPE html>
```

这将强制所有现代浏览器使用**标准模式**进行渲染。

## <!DOCTYPE> 与 DTD 的关系

虽然 HTML 5 不需要 DTD，但保留了 `<!DOCTYPE html>` 这个“开关”。它现在唯一的也是最重要的作用，就是**告诉浏览器启动标准模式渲染**，而不是为了去验证语法（因为已经不用 DTD 验了）。
