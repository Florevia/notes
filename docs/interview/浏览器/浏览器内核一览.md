# 浏览器内核一览

内核 = 渲染引擎 + JS 引擎 对照表

|  浏览器   | 渲染引擎 |    JS 引擎     |    俗称"内核"    |
| :-------: | :------: | :------------: | :--------------: |
|  Chrome   |  Blink   |       V8       |      Blink       |
|  Safari   |  WebKit  | JavaScriptCore |      WebKit      |
|  Firefox  |  Gecko   |  SpiderMonkey  |      Gecko       |
| Edge (新) |  Blink   |       V8       | Blink (Chromium) |
|    IE     | Trident  |     Chakra     |     Trident      |
