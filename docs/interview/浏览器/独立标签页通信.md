## 方案

### 基于 localStorage 事件监听

```js
// ====== 页面 A (发送方) ======
// 注意：如果 setItem 的值与旧值完全一样，是不会触发事件的。
// 实践中通常会带上时间戳或随机数，强制触发更新。
const msgData = { text: "刷新表格", timestamp: Date.now() };
localStorage.setItem("table_sync_msg", JSON.stringify(msgData));

// ====== 页面 B (接收方) ======
// 监听全局的 storage 事件
window.addEventListener("storage", (event) => {
  // 判断是否是我们关心的那个 key 被修改了
  if (event.key === "table_sync_msg") {
    // newValue 存放的是最新写入的字符串
    const data = JSON.parse(event.newValue);
    console.log("监听到本地存储变化:", data.text);
  }
});
```

### 基于 Broadcast Channel API

专为同源跨上下文通信设计

```js
// ====== 页面 A (发送方) ======
// 1. 实例化并连接到指定频道
const channel = new BroadcastChannel("my_app_channel");

// 2. 发送消息（支持发送对象等任意可序列化数据）
channel.postMessage({ type: "UPDATE_TABLE", rowId: 123 });

// ====== 页面 B (接收方) ======
// 1. 连接到同一个频道
const channel = new BroadcastChannel("my_app_channel");

// 2. 监听消息
channel.onmessage = (event) => {
  console.log("接收到兄弟页面的消息:", event.data);
  // 输出: { type: 'UPDATE_TABLE', rowId: 123 }
};

// 不用时记得关闭，避免内存泄漏
// channel.close();
```
