# 封装组件的具体实现

## 核心原则

1. **单一职责**: 每个组件只做一件事。
2. **通用性**: 避免包含特定业务逻辑。
3. **可配置性**: 通过 Props 和 Slots 提供灵活性。

## 实现细节

### 1. Props (属性)

- 定义组件的输入。
- 使用 TypeScript 接口定义 Props 类型。
- 提供默认值。

```typescript
interface Props {
  title: string;
  visible?: boolean;
}
withDefaults(defineProps<Props>(), {
  visible: false,
});
```

### 2. Events (事件)

- 定义组件的输出。
- 使用 `defineEmits` 声明事件。

```typescript
const emit = defineEmits<{
  (e: "update:visible", value: boolean): void;
  (e: "confirm", data: any): void;
}>();
```

### 3. Slots (插槽)

- 提供内容分发机制。
- 使用默认插槽、具名插槽和作用域插槽。

### 4. Expose (暴露)

- 使用 `defineExpose` 显式暴露组件内部的方法或属性供父组件调用（如 `open()`, `close()`）。

```typescript
const open = () => {
  /* ... */
};
defineExpose({ open });
```

## 差异化场景配置

- **样式覆盖**: 提供 `class` 或 `style` props，或使用 CSS 变量。
- **配置对象**: 对于复杂组件，可以传入一个配置对象 `options`。
- **插槽**: 允许用户完全自定义某部分内容。
