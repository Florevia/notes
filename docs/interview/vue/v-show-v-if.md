# v-show vs v-if

答题点：

- 渲染机制
- 生命周期触发
- 选择

## 核心机制区别

- v-if 是 **真正的条件渲染**： 它是“惰性”的。只有条件为真时，才会渲染DOM。当条件切换时，它会触发 **生命周期的销毁和重建** ，DOM 元素会从文档流中添加或移除。

- **v-show 是CSS 的切换**： 无论初始条件如何，元素始终会被渲染并保留在 DOM 中。通过切换 CSS 的 display 属性来控制元素的显示或者隐藏。

## 选择

- v-if： 不需频繁切换的场景（如用户权限控制、首屏加载时的骨架屏）。

- v-show：频繁地切换（如折叠面板、Tab 切换、模态框显示隐藏）

## 组件生命周期影响（重要）

- 使用 v-if 切换时，组件会完整走一遍 Unmounted -> Mounted 的流程（Vue 3 中是 onUnmounted -> onMounted）。

- 使用 v-show 切换时，组件始终保持 Mounted 状态，不会触发挂载/卸载钩子。
