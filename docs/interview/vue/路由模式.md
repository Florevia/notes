# 路由的两种模式

Vue Router 主要支持两种路由模式：Hash 模式和 HTML5 (History) 模式。

## 1. Hash 模式 (`createWebHashHistory`)

- **URL 格式**: `http://example.com/#/home`
- **原理**: 利用 `window.onhashchange` 事件监听 URL hash 值的变化。
- **特点**:
  - Hash 值不会被发送到服务器，只在客户端处理。
  - 兼容性好（支持旧版浏览器）。
  - 不需要服务器端配置。
  - URL 带有 `#`，不够美观。

## 2. HTML5 模式 (`createWebHistory`)

- **URL 格式**: `http://example.com/home`
- **原理**: 利用 HTML5 History API (`pushState`, `replaceState`, `popstate` 事件)。
- **特点**:
  - URL 看起来像正常的路径。
  - **需要服务器端配置**: 如果用户直接访问 `http://example.com/home`，服务器需要配置将所有 404 请求重定向到 `index.html`，否则会报 404 错误。

## 面试回答

- Vue Router 有两种路由模式：
  - Hash 模式和 History 模式。
  - Hash 模式是通过 URL 中的 `#` 来标识路由变化，利用浏览器的 `hashchange` 事件监听 URL 变化，因为 hash 部分不会被服务器处理，所以不需要额外的服务器配置。
  - History 模式是基于 HTML5 的 `History API`，比如 `pushState` 和 `popstate` 来修改 URL，实现无刷新路由跳转。它的 URL 更美观，但需要服务器配置将所有路由重定向到 `index.html`，否则刷新页面可能会出现 404。
