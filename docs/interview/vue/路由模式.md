# 路由的两种模式

Vue Router 主要支持两种路由模式：Hash 模式和 HTML5 (History) 模式。

## 1. Hash 模式 (`createWebHashHistory`)

- **URL 格式**: `http://example.com/#/home`
- **原理**: 利用 `hashchange` 事件监听 URL hash 值的变化。
- **特点**:
  - Hash 值不会被发送到服务器，只在客户端处理。
  - 兼容性好（支持旧版浏览器）。
  - 不需要服务器端配置。
  - URL 带有 `#`，不够美观。

## 2. HTML5 模式 (`createWebHistory`)

- **URL 格式**: `http://example.com/home`
- **原理**: 利用 HTML5 History API (`pushState`, `replaceState`, 以及 `popstate` 事件)。
- **特点**:
  - URL 看起来像正常的路径。
  - **需要服务器端配置**: 如果用户直接访问 `http://example.com/home`，服务器需要配置将所有 404 请求重定向到 `index.html`，否则会报 404 错误。

## 面试回答

- Vue Router 有两种路由模式：
  - Hash 模式和 History 模式。
  - Hash 模式是通过 URL 中的 `#` 来标识路由变化，利用浏览器的 `hashchange` 事件监听 URL 变化，因为 hash 部分不会被服务器处理，所以不需要额外的服务器配置。

    ```js
    window.addEventListener("hashchange", () => {
      // 获取当前的 hash 值
      const currentPath = window.location.hash.slice(1);
      // 根据 currentPath 去路由表里匹配对应的 Vue 组件，并渲染到 <router-view> 中
    });
    ```

  - History 模式是基于 HTML5 的 `History API`，比如 `pushState` 和 `replaceState` 来修改 URL，通过监听 `popstate` 事件，实现无刷新路由跳转。它的 URL 更美观，但需要服务器配置将所有路由重定向到 `index.html`，否则刷新页面可能会出现 404。

```js
// 监听浏览器的前进/后退事件
window.addEventListener("popstate", () => {
  // 获取当前的路径
  const currentPath = window.location.pathname;
  // 根据 currentPath 去路由表里匹配对应的 Vue 组件，并渲染到 <router-view> 中
});
```
