# 组件间通信方式

## 重点

- props/emit
- v-model
- Vuex/Pinia
- Provide/Inject

## 父子组件通信

- 这是 **最基础** 且符合 **单向数据流** 原则的通信方式。

### Props / Emits

- Props：父传子，属于单向绑定。
- Emits：子传父，通过触发自定义事件通知父组件更新。

```vue
<!-- 父组件 -->
<ChildComponent :propName="propValue" @custom-event="handleCustomEvent" />

<!-- 子组件 -->
<template>
  <div>
    {{ propName }}
  </div>
  <button @click="handleClick">Click me</button>
</template>

<script setup>
const props = defineProps({
  propName: {
    type: String,
    required: true,
  },
});

const emit = defineEmits(["custom-event"]);

function handleClick() {
  emit("custom-event", "some data");
}
</script>
```

### style 和 class 的绑定

父组件在子组件标签上写的 **class** 和 **style**，默认会自动合并（挂载）到子组件的根元素上。

```vue
<!-- 父组件 -->
<Child class="red-box" style="color: red;" />

<!-- 子组件渲染结果 -->
<div class="child-root red-box" style="color: red;">...</div>
```

### attributes 的绑定

- 父组件传了 props，但子组件没有声明接收（没写在 props 选项里）。这些属性会保存在 `$attrs` 中。**常用于高阶组件封装，透传属性**

> **注意**：通常配合 `inheritAttrs: false` 使用，防止属性被自动挂载到根元素上，而是通过 `v-bind="$attrs"` 显式挂载到内部特定元素。

```vue
<!-- 父组件 -->
<BaseInput placeholder="请输入" type="text" />

<!-- 子组件 (未声明 placeholder) -->
<template>
  <!-- v-bind="$attrs" 可以把父组件传来的“多余”属性全部透传给内部的原生 input -->
  <input v-bind="$attrs" />
</template>
```

### native 修饰符

- 在 Vue 2 中，想监听组件根元素的原生事件（如 click），必须加 `.native`，否则会被当做自定义事件。

> **注意**：Vue 3 中已移除该修饰符，Vue 3 自动智能识别。

```vue
<!-- Vue 2 -->
<Child @click.native="handleClick" />
```

### sync 修饰符

- Vue 2 中用于对 prop 进行“双向绑定”的语法糖。

> **注意**：Vue 3 中已移除，被合并统一到了 v-model 的参数写法中（如 `v-model:title="..."`）

```vue
<!-- Vue 2 -->
<Child :title.sync="pageTitle" />
<!-- 等价于 -->
<Child :title="pageTitle" @update:title="pageTitle = $event" />
```

### ref

- 父组件通过 ref 获取子组件实例，从而直接调用子组件的方法或访问其属性。

- 注意：在 `<script setup>` 中，子组件必须通过 defineExpose 显式暴露成员，父组件才能访问。

vue2:

```vue
<!-- 父组件 -->
<template>
  <Child ref="childComp" />
</template>

<script>
export default {
  mounted() {
    this.$refs.childComp.someMethod(); // 调用子组件方法
  },
};
</script>
```

vue3:

```vue
<!-- parent.vue -->
<script setup>
import { ref, onMounted } from "vue";

const childComp = ref(null);

onMounted(() => {
  // 必须等组件挂载后才能访问 ref
  childComp.value.someMethod();
});
</script>

<template>
  <Child ref="childComp" />
</template>

<!-- child.vue -->
<script setup>
defineExpose({
  someMethod() {
    console.log("someMethod");
  },
});
</script>
```

### v-model (双向绑定)

- 双向绑定的语法糖。

- **Vue 2**：

  - **组件**：默认为 `value` prop + `input` 事件。
  - **原生元素**：智能映射（如 text 对应 `value/input`，checkbox 对应 `checked/change`）。

- **Vue 3**：
  - **组件**：默认为 `modelValue` prop + `update:modelValue` 事件。
  - **新特性**：支持定义多个 `v-model`（如 `v-model:title`），从而替代了 Vue 2 的 `.sync` 修饰符。

## 跨层级通信

### Provide / Inject (依赖注入)

- 原理：祖先组件定义 provide，所有后代组件都可以通过 inject 接收（核心规则：单向数据流维护）。

- 建议 provide 传递 ref 或 reactive 对象。为了遵循单向数据流，建议在 provide 端定义修改数据的方法并一并传出。

options API：

```js
// 祖先组件
export default {
  provide() {
    return {
      theme: 'dark',
      count: this.count  // 注意：这样传的不是响应式的
    }
  }
}

// 后代组件
export default {
  inject: ['theme', 'count']
  // 或者带默认值：
  // inject: {
  //   theme: { default: 'light' }
  // }
}
```

composition API:

```js
// 祖先组件
import { provide, ref } from "vue";

const count = ref(0);
const increment = () => count.value++;

provide("count", count); // 传递响应式 ref
provide("increment", increment); // 传递方法

// 后代组件
import { inject } from "vue";

const count = inject("count"); // 获取响应式 ref
const increment = inject("increment", () => {}); // 带默认值
```

### router

- 通过 URL 传参。

  - params：路径参数（/user/:id）
  - query：查询参数（/user?id=123）

```js
// params
this.$route.params.id;

// query
this.$route.query.id;
```

### store

简单应用不至于上 Vuex，可以单独建一个 reactive 对象作为 store。

```js
// store.js
const store = reactive({
  count: 0,
  increment() {
    store.count++;
  },
});

// app.vue
// 方法一：使用 Computed (推荐)
import { store } from "./store";

export default {
  computed: {
    msg() {
      return store.count; // 依赖追踪生效
    },
  },
};
```

```vue
<!-- 方法二：使用 Vue 3 Setup 语法 (最推荐) -->
<script setup>
import { store } from "./store";
// 在模板里直接用 store.count，或者解构（需配合 toRefs 保持响应式）
import { toRefs } from "vue";
const { count } = toRefs(store);
</script>

<template>
  <div>{{ store.count }}</div>
  <div>{{ count }}</div>
</template>
```

```vue
<!-- 在模板里直接用 store.count，或者解构（需配合 toRefs 保持响应式） -->
<script setup>
import { store } from "./store";
import { toRefs } from "vue";
const { count } = toRefs(store);
</script>

<template>
  <div>{{ count }}</div>
</template>
```

### 全局事件总线 (Event Bus)

全局事件总线的本质是一个**单例对象**，它在所有组件都能访问到的地方（通常是全局）维护一个事件中心，具备两个核心能力：

1. **发布 (Emit)**：触发事件并传递数据。
2. **订阅 (On)**：监听事件并接收数据。

缺点：

1. **数据流向不明**
2. **命名冲突**
3. **容易内存泄漏**

---

#### Vue 2 (Legacy)

在 Vue 2 中，每一个 Vue 实例都内置了三个核心方法：

- `$on(eventName, callback)`：监听（订阅）事件。

- `$emit(eventName, data)`：触发（发布）事件。

- `$off(eventName)`：移除（取消订阅）事件。

```js
// main.js 安装全局事件总线
import Vue from "vue";
import App from "./App.vue";

new Vue({
  beforeCreate() {
    // 安装全局事件总线，$bus 就是当前应用的 vm
    Vue.prototype.$bus = this;
  },
  render: (h) => h(App),
}).$mount("#app");
```

```js
// A组件：发送者
export default {
  methods: {
    sendData() {
      // 触发名为 'receiveMessage' 的事件，并传递数据
      this.$bus.$emit("receiveMessage", "你好，我是来自A组件的消息！");
    },
  },
};
```

```js
// B组件：接收者
export default {
  mounted() {
    // 监听事件
    this.$bus.$on("receiveMessage", (data) => {
      console.log("B组件收到了数据：", data);
    });
  },
  // 重要：在组件销毁前解绑事件，防止内存泄漏
  beforeDestroy() {
    this.$bus.$off("receiveMessage");
  },
};
```

---

#### Vue 3 (Recommended: mitt)

Vue 3 移除了实例上的 `$on`, `$off` 和 `$once` 方法，因此无法像 Vue 2 那样直接使用 Vue 实例作为 Event Bus。官方推荐使用轻量级库 `mitt`。

#### 1. 安装

```bash
npm install mitt
```

#### 2. 封装 (utils/bus.js)

```js
import mitt from "mitt";

const bus = mitt();
export default bus;
```

#### 3. 使用

```js
// 发送事件 (Component A)
import bus from "@/utils/bus";

function handleClick() {
  bus.emit("foo", { a: "b" });
}

// 接收事件 (Component B)
import bus from "@/utils/bus";
import { onMounted, onUnmounted } from "vue";

// 必须在组件销毁时解绑，否则会造成内存泄漏
const handler = (e) => console.log("foo:", e);

onMounted(() => {
  bus.on("foo", handler);
});

onUnmounted(() => {
  bus.off("foo", handler);
});
```

## 推荐

| 关系类型       | 推荐方式            | 理由                               |
| -------------- | ------------------- | ---------------------------------- |
| 直接父子       | props / emits       | 最标准、易追踪的数据流。           |
| 深层嵌套       | provide / inject    | 避免多层 Prop 透传，降低耦合。     |
| 全局/多处共享  | Pinia               | 结构化存储，支持持久化和调试工具。 |
| 解耦的任意组件 | mitt 或 Composables | 适用于没有明确层级关系的逻辑联动。 |
| 二次封装组件   | $attrs              | 实现对原始属性的完美继承。         |
