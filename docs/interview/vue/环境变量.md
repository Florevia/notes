# vue-cli/webpack & vite 环境变量

## 作用

- 将代码与配置分离。
- 同一套代码，在开发环境（Dev）、测试环境（Stage/Test）和生产环境（Prod）能够自动连接 **不同的后端地址**、开启 **不同的功能开关**，而无需手动修改代码。

## 核心差异

| 特性        | Vue CLI (Webpack)               | Vite                       |
| ----------- | ------------------------------- | -------------------------- |
| 必须前缀    | `VUE_APP_`                      | `VITE_`                    |
| JS 读取方式 | `process.env.VUE_APP_XXX`       | `import.meta.env.VITE_XXX` |
| HTML 插值   | `<%= VUE_APP_XXX %>` (EJS 语法) | `%VITE_XXX%` (文本替换)    |
| 底层机制    | Webpack DefinePlugin            | Rollup replace + dotenv    |
| 特殊变量    | `process.env.NODE_ENV`          | `import.meta.env.MODE`     |

## 目录结构

根目录下创建`.env` `.env.development` `.env.production`文件

## 步骤

1. 配置环境变量

2. 使用

- JS 读取

vue-cli

```js
process.env.VUE_APP_XXX;
```

vite

```js
import.meta.env.VITE_XXX;
```

- HTML 插值

vue-cli

```html
<!DOCTYPE html>
<html lang="zh">
  <head>
    <meta charset="utf-8" />
    <title><%= VUE_APP_TITLE %></title>
  </head>
  <body>
    <div id="app"></div>
  </body>
</html>
```

vite

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>%VITE_APP_TITLE%</title>
  </head>
  <body>
    <div id="app"></div>
    <script type="module" src="/src/main.ts"></script>
  </body>
</html>
```
