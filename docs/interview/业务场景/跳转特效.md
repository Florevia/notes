# 跳转特效

页面跳转特效 是现代 Web 应用（尤其是 SPA 单页应用）中极其重要的一环。它能消除页面直接刷新带来的“生硬感”和“白屏闪烁”，为用户提供空间方向感（比如“前进”是向左推，“后退”是向右拉），从而营造出类似原生 App 的流畅体验。

## 方案一：Vue `<Transition>` + Vue Router（SPA 主流方案）

### 核心原理

Vue 的 `<Transition>` 组件会在元素**进入/离开 DOM** 时自动添加 CSS 类名，配合 `<RouterView>` 的 `v-slot`，就可以在路由切换时触发过渡动画。

### 1. 基础结构

```vue
<!-- App.vue -->
<template>
  <RouterView v-slot="{ Component, route }">
    <Transition :name="transitionName" mode="out-in">
      <component :is="Component" :key="route.path" />
    </Transition>
  </RouterView>
</template>

<script setup>
import { ref, watch } from "vue";
import { useRouter } from "vue-router";

const router = useRouter();
const transitionName = ref("slide-left");

// 根据路由的 meta.index 判断前进/后退方向
watch(
  () => router.currentRoute.value,
  (to, from) => {
    const toIndex = to.meta.index ?? 0;
    const fromIndex = from.meta.index ?? 0;
    transitionName.value = toIndex > fromIndex ? "slide-left" : "slide-right";
  },
);
</script>
```

### 2. 路由配置 — 标记层级

```js
const routes = [
  { path: "/", component: Home, meta: { index: 0 } },
  { path: "/list", component: List, meta: { index: 1 } },
  { path: "/detail", component: Detail, meta: { index: 2 } },
];
```

### 3. CSS 过渡动画

```css
/* 向左滑入（"前进"效果） */
.slide-left-enter-active,
.slide-left-leave-active {
  transition: all 0.3s ease;
}
.slide-left-enter-from {
  transform: translateX(100%); /* 新页面从右边进来 */
  opacity: 0;
}
.slide-left-leave-to {
  transform: translateX(-30%); /* 旧页面向左退出 */
  opacity: 0;
}

/* 向右滑入（"后退"效果） */
.slide-right-enter-active,
.slide-right-leave-active {
  transition: all 0.3s ease;
}
.slide-right-enter-from {
  transform: translateX(-100%); /* 新页面从左边进来 */
  opacity: 0;
}
.slide-right-leave-to {
  transform: translateX(30%); /* 旧页面向右退出 */
  opacity: 0;
}
```

### 4. Transition 类名生命周期

```
进入阶段：                     离开阶段：
┌─────────────────────┐       ┌─────────────────────┐
│ .xxx-enter-from     │──┐    │ .xxx-leave-from     │──┐
│ (初始状态)           │  │    │ (初始状态)           │  │
└─────────────────────┘  │    └─────────────────────┘  │
                         ▼                              ▼
┌─────────────────────┐       ┌─────────────────────┐
│ .xxx-enter-active   │       │ .xxx-leave-active   │
│ (过渡中，定义动画)    │       │ (过渡中，定义动画)    │
└─────────────────────┘       └─────────────────────┘
           │                             │
           ▼                             ▼
┌─────────────────────┐       ┌─────────────────────┐
│ .xxx-enter-to       │       │ .xxx-leave-to       │
│ (最终状态)           │       │ (最终状态)           │
└─────────────────────┘       └─────────────────────┘
```

### `mode` 属性

| 值       | 行为                           | 适用场景                   |
| :------- | :----------------------------- | :------------------------- |
| `out-in` | 旧元素**先离开**，新元素再进入 | 大多数页面切换             |
| `in-out` | 新元素**先进入**，旧元素再离开 | 卡片堆叠效果               |
| 不设置   | 进入和离开**同时进行**         | 左右滑动切换（需绝对定位） |

## 面试回答要点

> **"你们项目中是怎么实现的？"**

1. **SPA 项目**用 Vue 的 `<Transition>` + `<RouterView v-slot>` 实现，通过路由 `meta.index` 判断前进后退方向，动态切换 `slide-left` / `slide-right` 动画。
2. 用 `mode="out-in"` 保证旧页面先退出、新页面再进入，避免两个页面同时出现导致布局错乱。
3. 对性能敏感的动画使用 `transform` 和 `opacity`（触发 GPU 合成层），避免使用 `left/top/width` 等触发重排的属性。
