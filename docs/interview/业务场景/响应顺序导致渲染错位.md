# 响应顺序导致渲染错位

## 场景

- 搜索联想 / 输入框实时请求
- 切换 tab / 筛选条件
- 列表快速翻页

- 解决思想：锁定id，对应渲染

## 思路一：只认最后一次请求

给每次请求一个递增 id，返回时判断是不是 **当前最新请求**，不是就丢弃。

```js
let latestRequestId = 0;

async function fetchData(query) {
  const requestId = ++latestRequestId;

  try {
    const res = await fetch(`/api/search?q=${encodeURIComponent(query)}`);
    const data = await res.json();
    //响应回来时，用局部的 requestId 和最新的 latestRequestId 对比
    // 不是最新请求，直接忽略
    if (requestId !== latestRequestId) return;

    render(data);
  } catch (err) {
    if (requestId !== latestRequestId) return;
    console.error(err);
  }
}
```

## 思路二：取消旧请求

用 AbortController，发新请求前把上一个取消掉。

```js
let controller = null;

async function fetchData(query) {
  // 取消上一次请求
  if (controller) {
    controller.abort();
  }

  controller = new AbortController();

  try {
    const res = await fetch(`/api/search?q=${encodeURIComponent(query)}`, {
      signal: controller.signal,
    });
    const data = await res.json();
    render(data);
  } catch (err) {
    if (err.name === "AbortError") {
      // 被主动取消，忽略即可
      return;
    }
    console.error(err);
  }
}
```

## 思路三：按顺序串行执行

如果业务上必须按顺序处理，就不要并发发请求，而是排队一个个执行。

```js
let queue = Promise.resolve();

function fetchInOrder(query) {
  queue = queue
    .then(async () => {
      const res = await fetch(`/api/search?q=${encodeURIComponent(query)}`);

      // 串行执行，后一个请求必须等前一个请求执行完才开始
      const data = await res.json();
      render(data);
    })
    .catch(console.error);

  return queue;
}
```
