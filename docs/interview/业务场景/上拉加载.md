# 上拉加载

## 1. 封装组件：`LazyLoadList.vue`

这个组件只负责“骨架”和“触底检测”，具体的数据渲染交给父组件的 `slot`。

```vue
<template>
  <div class="lazy-load-container">
    <slot></slot>

    <div ref="loadingRef" class="loading-trigger">
      <span v-if="isLoading">加载中...</span>
      <span v-else-if="isFinished">没有更多数据了</span>
      <span v-else>上拉加载更多</span>
    </div>
  </div>
</template>

<script setup>
import { ref, onMounted, onUnmounted } from "vue";

// 3. 定义属性和方法
const props = defineProps({
  // 通过 modelValue 接收父组件的 v-model，标记是否处于加载中
  modelValue: {
    type: Boolean,
    default: false,
  },
  // 表示数据是否全部加载完成
  isFinished: {
    type: Boolean,
    default: false,
  },
});

const emit = defineEmits(["update:modelValue", "onLoad"]);

const loadingRef = ref(null);
let observer = null;

onMounted(() => {
  // 2. 监听 loading 是否可见
  observer = new IntersectionObserver((entries) => {
    const target = entries[0];
    // 如果 dom 可见，且当前没有在加载中，且数据还没全部加载完
    if (target.isIntersecting && !props.modelValue && !props.isFinished) {
      // 修改父组件的 isLoading 状态为 true
      emit("update:modelValue", true);
      // 抛出 onLoad 事件，通知父组件去获取数据
      emit("onLoad");
    }
  });

  if (loadingRef.value) {
    observer.observe(loadingRef.value);
  }
});

onUnmounted(() => {
  if (observer) observer.disconnect();
});
</script>

<style scoped>
.loading-trigger {
  text-align: center;
  padding: 20px;
  color: #999;
}
</style>
```

## 2. 父组件如何使用：`App.vue`

父组件负责维护真实的数据源，并模拟网络请求。

```vue
<template>
  <div class="app-container">
    <h2>数据懒加载 Demo</h2>

    <LazyLoadList v-model="loading" :isFinished="finished" @onLoad="fetchData">
      <div class="list-item" v-for="item in list" :key="item">
        我是数据项：{{ item }}
      </div>
    </LazyLoadList>
  </div>
</template>

<script setup>
import { ref } from "vue";
import LazyLoadList from "./LazyLoadList.vue";

const list = ref([]);
// 对应组件内的 modelValue (isLoading)
const loading = ref(false);
// 对应组件内的 isFinished
const finished = ref(false);

// 模拟向后端请求数据
const fetchData = () => {
  setTimeout(() => {
    // 假设每次加载 10 条数据
    const currentLength = list.value.length;
    for (let i = 1; i <= 10; i++) {
      list.value.push(currentLength + i);
    }

    // 重点：数据请求回来后，必须把 loading 状态改回 false，以便下一次触发
    loading.value = false;

    // 模拟数据加载完毕（假设后端总共只有 30 条数据）
    if (list.value.length >= 30) {
      finished.value = true;
    }
  }, 1000); // 模拟 1 秒的网络延迟
};

// 初始化时先加载第一屏数据
fetchData();
</script>

<style scoped>
.app-container {
  height: 400px; /* 父容器固定高度 */
  overflow-y: auto; /* 允许滚动 */
  border: 1px solid #ccc;
  width: 300px;
}
.list-item {
  height: 60px;
  line-height: 60px;
  border-bottom: 1px solid #eee;
  text-align: center;
}
</style>
```

## 核心逻辑回归图片：

1. **创建组件、插入 slot、放置 loading DOM**：都在 `LazyLoadList.vue` 的 `<template>` 中完成。
2. **监听可见性**：通过 `new IntersectionObserver` 实现。只要底部的文字（上拉加载更多）露出来了，就说明滑到底了。
3. **状态流转**：

- 到底部 -> 触发 `update:modelValue(true)` (也就是父组件的 `loading = true`) -> 抛出 `onLoad`。
- 父组件接收到 `onLoad` -> 发送 Ajax 请求拿数据。
- 请求结束 -> 父组件将 `loading` 改回 `false`，如果没数据了将 `finished` 设为 `true`。

这种实现方式比起传统的监听 `window.onscroll` 去计算 `scrollTop` 和 `scrollHeight` 要优雅得多，性能也更好，因为交叉观察器是浏览器底层的异步 API。
