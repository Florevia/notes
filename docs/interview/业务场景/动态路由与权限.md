# 基于 RBAC 的动态路由和权限控制

**RBAC (Role-Based Access Control)**: 基于角色的访问控制。

## 实现流程

### 1. 定义路由表

通常分为两部分：

- **静态路由 (Constant Routes)**: 所有人可见（如登录页、404）。
- **动态路由 (Async Routes)**: 需要权限才能访问，配置 `meta: { roles: ['admin', 'editor'] }`。

### 2. 登录与获取权限

1. 用户登录，后端返回 `token`。
2. 前端根据 `token` 获取用户信息（包含 `roles` 角色列表）。

### 3. 生成可访问路由

在全局前置守卫 (`router.beforeEach`) 中：

1. 判断是否有 token。
2. 如果有 token 但无角色信息，请求获取用户信息。
3. 根据用户角色，过滤动态路由表。
4. 使用 `router.addRoute()` 动态添加过滤后的路由。

```javascript
// store/permission.js
function filterAsyncRoutes(routes, roles) {
  const res = [];
  routes.forEach((route) => {
    const tmp = { ...route };
    if (hasPermission(roles, tmp)) {
      if (tmp.children) {
        tmp.children = filterAsyncRoutes(tmp.children, roles);
      }
      res.push(tmp);
    }
  });
  return res;
}
```

### 4. 菜单渲染

根据生成的路由表渲染侧边栏菜单。

### 5.页面级/按钮级权限

- **指令 (`v-permission`)**: 控制按钮显示/隐藏。
- **Hooks (`usePermission`)**: 在逻辑中判断权限。
