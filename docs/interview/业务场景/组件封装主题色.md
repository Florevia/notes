# 组件封装主题色

## 需求

组件复用时可以改主题色。

## 思路

> 不把颜色写死在组件里面，而是把颜色从组件实现里抽离出来，做成一套可配置的主题能力。

1. 定义语义化颜色。

   比如组件里不用 **蓝色、红色** 这种写法，而是定义成 **主色、成功色、警告色、文字色、边框色** 这类语义化的 `token`。

2. 组件内部只去消费这些语义 `token`，不直接依赖某个固定颜色值。

   它可以来自 **CSS 变量**，也可以来自 **theme 配置对象**，或者来自全局的 **ThemeProvider**。

   这样做的好处是组件和主题机制解耦，后续要换主题方案时，组件本身不需要大改。

3. 对外提供一个明确的主题入口。

   让使用方通过配置去改，而不是通过覆盖内部样式去改。

   比如 **全局主题配置、Provider 注入，或者 token 覆盖能力**。

4. 考虑到主题色不只是一个颜色值的问题。

   一个完整的组件通常会有 **默认态、悬停态、点击态、禁用态、聚焦态** 这些状态，所以在设计相关的衍生色和状态色。

   确保别人改完主题以后，整个交互状态是统一的，不会出现默认态改了但 hover 还是旧颜色的情况。

5. 在落地上保留一套默认主题，保证组件开箱即用。

   同时允许业务方按需覆盖。这样既能保证基础体验，也能兼顾定制化。

## 实现

### 用到的API

1. `defineProps()`
2. `computed()`
3. `provide()`
4. `inject()`
5. `:style`

### 示例代码

业务方传 theme → ThemeProvider 接收 → 和默认主题合并 → 转成 CSS 变量 → 子组件通过 var(...) 消费

#### 1. 定义默认主题

theme.js

```js
// 语义化字段
export const defaultTheme = {
  colorPrimary: "#1677ff",
  colorPrimaryHover: "#4096ff",
  colorPrimaryActive: "#0958d9",
  colorTextOnPrimary: "#ffffff",
  borderRadius: "6px",
};
```

#### 2. 实现ThemeProvider

ThemeProvider.vue

```vue
<script setup>
import { computed, provide } from "vue";
import { defaultTheme } from "./theme";

const props = defineProps({
  theme: {
    type: Object,
    default: () => ({}),
  },
});

// 1. 合并默认主题和外部传入主题
const mergedTheme = computed(() => {
  return {
    ...defaultTheme,
    ...props.theme,
  };
});

// 2. 提供给后代组件使用（JS逻辑层可取）
provide("theme", mergedTheme);

// 3. 转成 CSS 变量，供样式层消费
const cssVars = computed(() => {
  return {
    "--color-primary": mergedTheme.value.colorPrimary,
    "--color-primary-hover": mergedTheme.value.colorPrimaryHover,
    "--color-primary-active": mergedTheme.value.colorPrimaryActive,
    "--color-text-on-primary": mergedTheme.value.colorTextOnPrimary,
    "--border-radius": mergedTheme.value.borderRadius,
  };
});
</script>

<template>
  <div :style="cssVars">
    <slot />
  </div>
</template>
```

#### 3. 按钮组件

MyButton.vue

```vue
<script setup>
defineProps({
  disabled: {
    type: Boolean,
    default: false,
  },
});
</script>

<template>
  <button class="my-button" :disabled="disabled">
    <slot />
  </button>
</template>

<style scoped>
.my-button {
  background: var(--color-primary);
  color: var(--color-text-on-primary);
  border: none;
  border-radius: var(--border-radius);
  padding: 8px 16px;
  cursor: pointer;
  transition: background 0.2s ease;
}

.my-button:hover {
  background: var(--color-primary-hover);
}

.my-button:active {
  background: var(--color-primary-active);
}

.my-button:disabled {
  background: #d9d9d9;
  color: #999;
  cursor: not-allowed;
}
</style>
```

#### 4. 页面中使用

App.vue

```vue
<script setup>
import ThemeProvider from "./ThemeProvider.vue";
import MyButton from "./MyButton.vue";
</script>

<template>
  <ThemeProvider
    :theme="{
      colorPrimary: '#7c3aed',
      colorPrimaryHover: '#8b5cf6',
      colorPrimaryActive: '#6d28d9',
      borderRadius: '12px',
    }"
  >
    <MyButton>提交</MyButton>
  </ThemeProvider>
</template>
```
