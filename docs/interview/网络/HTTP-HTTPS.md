# HTTPS 为什么更安全

总：HTTP 是明文传输；HTTPS 则是 HTTP + SSL/TLS 协议，通过加密通道进行传输。

1.  防窃听（数据加密）

> 机制：混合加密。

- 在建立连接（握手）阶段，使用非对称加密（公钥/私钥）来安全地交换密钥。

- 在后续的数据传输阶段，使用对称加密（因为速度快）来传输实际内容。

2. 防篡改（数据一致性）

> 机制：哈希摘要（MAC）。

- 每一份数据都会附带一个校验和（类似于数字指纹）。

- 如果中间人篡改了数据，接收方计算出的哈希值就会不匹配，从而发现篡改。

3. 防冒充（身份认证）

> 机制：数字证书（CA）。

- 服务器必须向权威机构（CA）申请证书。浏览器内置了受信任的 CA 根证书列表。

- 黑客可以伪造一个加密的连接，但他拿不出受信任的证书（比如他没法伪造 google.com 的证书），浏览器就会报红警告。
