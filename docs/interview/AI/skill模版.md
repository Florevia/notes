# Skill Name

## Purpose

一句话说明这个 skill 的目标。

## When to Use

列出应该触发的典型场景。

## Inputs

说明通常会收到什么输入。

## Process

按步骤写模型该怎么做。

## Output Format

规定输出结构、模板、字段。

## Rules

写边界、限制、禁止事项。

## Examples

给 1-2 个输入输出示例。

你可以这样理解每一部分的作用：

- frontmatter：解决“什么时候触发”
- When to Use：补充触发边界
- Process：解决“触发后怎么做”
- Output Format：解决“最后怎么输出”
- Rules：解决“不要做错什么”
- Examples：解决“让行为更稳定”
