# 原子扣费

## 概念
- 要么 **所有** 扣费操作都成功完成
- 要么 **所有** 操作都不执行（回滚到初始状态）
- 不存在"部分成功"的中间状态

## MongoDB & Mongoose 实现原子扣费

`findOneAndUpdate` 是 MongoDB 和 Mongoose 中的一个常用方法，用于 **查找并更新单个文档**。

它的核心特点是：

1. **原子性操作**（查找和更新在一个步骤中完成）
2. 可以返回更新前或更新后的文档
3. 比先 findOne 再 save 更高效、更安全


### 一、性能对比

| 操作 | 数据库交互次数 | 网络开销 |
|------|---------------|---------|
| `findOneAndUpdate` | **1次** | 小 |
| `findOne` + `save` | **2次** | 大 |

### 二、并发问题

- findOne + save 的并发问题（丢失更新）
- findOneAndUpdate 如何解决并发问题

`findOneAndUpdate` 在数据库层面是原子操作，MongoDB 会给文档 **加锁**，确保同一时间只有一个更新能执行：

```javascript
// 用户初始余额：1000元

// 请求A：扣100元
async function requestA() {
  await User.findOneAndUpdate(
    { _id: 1 },
    { $inc: { balance: -100 } }  // $inc 在数据库端原子执行
  );
}

// 请求B：扣200元
async function requestB() {
  await User.findOneAndUpdate(
    { _id: 1 },
    { $inc: { balance: -200 } }
  );
}

// 同时执行两个请求
Promise.all([requestA(), requestB()]);

// 最终结果：balance = 700 ✓ 正确！
```

### 三、其他安全优势

#### 1. 使用更新操作符更安全
```javascript
// ❌ 不安全：直接赋值（容易覆盖）
user.balance = user.balance - 100;

// ✅ 安全：使用 $inc（在数据库端计算）
{ $inc: { balance: -100 } }

// 其他常用更新操作符：
// $set - 设置字段
// $push - 数组添加元素
// $addToSet - 数组添加不重复元素
// $pull - 数组删除元素
```

#### 2. 可以带查询条件确保数据一致性
```javascript
// 只有余额足够时才扣款（乐观锁思想）
const result = await User.findOneAndUpdate(
  { 
    _id: userId, 
    balance: { $gte: 100 }  // 余额 >= 100 才更新
  },
  { $inc: { balance: -100 } },
  { new: true }
);

if (!result) {
  throw new Error('余额不足');
}
```
### 四、对比总结

| 对比项 | findOneAndUpdate | findOne + save |
|--------|------------------|----------------|
| **原子性** | ✅ 原子操作 | ❌ 非原子 |
| **并发安全** | ✅ 天然解决 | ❌ 容易丢失更新 |
| **性能** | 1次数据库请求 | 2次数据库请求 |
| **网络开销** | 小 | 大 |
| **适用场景** | 简单更新、并发场景 | 需要读取后复杂逻辑修改 |
| **中间件** | 触发 `findOneAndUpdate` | 触发 `save` |

### 五、原子扣费最佳实践

```javascript
// 原子扣费的完整示例
async function atomicDeduct(userId, amount) {
  const result = await User.findOneAndUpdate(
    {
      _id: userId,
      balance: { $gte: amount },  // 余额检查
      status: 'active'  // 账户状态检查
    },
    {
      $inc: { balance: -amount },
      $push: {
        transactions: {
          type: 'deduct',
          amount,
          createdAt: new Date()
        }
      }
    },
    {
      new: true,  // 返回更新后的文档
      runValidators: true  // 开启验证
    }
  );

  if (!result) {
    throw new Error('扣款失败：余额不足或账户异常');
  }

  return result;
}
```
