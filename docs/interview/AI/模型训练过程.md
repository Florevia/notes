# 模型训练过程

## 数据准备

- 收集大量文本、代码、图片或其他数据，然后做清洗：
  - 去重
  - 过滤低质量内容
  - 去掉违规或噪声数据
  - 做分词或 token 化

## 预训练（pre-training）

- 任务：根据前面的内容，预测下一个 token 是什么
- 产物： base model
- 认识：
  - 语言规律
  - 常识模式
  - 推理的部分结构
  - 代码模式
  - 写作风格

## 监督微调（Supervised Fine-Tuning，SFT）

- 任务：听得懂人话
- 数据：指令-回答

### LoRA

#### 概念

LoRA（Low-Rank Adaptation，低秩自适应）属于 AI 模型训练的底层技术

#### 核心原理：给大模型挂“外挂”

- 传统的 **全量微调（Full Fine-tuning）** 相当于要把大模型的所有参数重新算一遍，这需要极其昂贵的算力（几十张 A100 显卡）。

- LoRA 的做法是：冻结住原本大模型的权重参数不改动，而是在旁边“旁路”插入两个非常小的 **低秩矩阵（Low-Rank Matrices）** 进行训练。

> 形象比喻：这就好比我们不需要重写整本《百科全书》（基础模型），只需要在某一页贴上一张“便利贴”（LoRA 权重），上面写上我们需要补充或修正的知识。

## 对齐训练（Alignment）

### 基于人类反馈的强化学习（RLHF）

- 任务：让模型输出更符合“人类想要的好回答”
- 过程：
  - 采样多个回答
  - 人工排序
  - 训练奖励模型
  - 强化学习
