# 提示词工程

## 概念

**提示词工程（Prompt Engineering）** 是一种通过 **优化输入文本（Prompt）** 来引导大语言模型（LLM）生成准确、高质量输出的技术学科。

本质上，它是在 **不更新模型参数（权重）** 的前提下，利用模型具备的 **上下文学习能力（In-Context Learning）**，通过设计 **特定的指令结构**、**提供示例** 或 **思维链**，以此挖掘和激发模型潜在能力的过程。

## 核心原则

1. **清晰性 (Clarity)**：指令必须明确无歧义，避免模糊不清的表述。
2. **具体性 (Specificity)**：提供足够的上下文和细节，帮助模型理解任务要求。
3. **约束性 (Constraint)**：设定明确的输出格式、长度或风格限制，引导模型生成符合预期的结果。
4. **示例性 (Exemplarity)**：通过提供示例（Few-Shot Learning）来展示期望的输入输出模式，帮助模型更好地理解任务。
5. **迭代性 (Iteration)**：根据模型输出不断调整和优化提示词，这是一个持续改进的过程。
