# CSS 单位

## 1. 绝对单位

不管在什么设备、什么屏幕上，单位的大小都是**固定的**。

- **px**: 像素。在屏幕上，1px 对应一个物理像素点（在高分屏 Retina 上可能对应多个物理像素）。适合精确控制尺寸。

_适用场景：打印媒体、或者对尺寸要求极其精确且不考虑响应式的布局。_

## 2. 相对单位

它们的大小不是固定的，而是**相对于**另一个长度计算出来的。这是响应式开发的核心。

### 字体相关

- **em**:

  - 用在 `font-size` 时：相对于**父元素**的字体大小。

  - 用在其他属性 (如 `width`, `padding`) 时：相对于**当前元素自己**的字体大小。

  - _缺点_：嵌套多了容易算晕（比如父子都是 1.5em，最后孙子就是 2.25 倍）。

- **rem (Root em)**:

  - 永远相对于根元素 `<html>` 的字体大小。

  - 默认情况下，浏览器 `<html>` 字体是 16px，所以 `1rem = 16px`。

  - _优点_：非常稳定，没有嵌套计算问题，是移动端适配的主流选择。

### 视口相关

- **vw**: 1vw = 视口宽度的 1%。
- **vh**: 1vh = 视口高度的 1%。
- **vmin**: 取 vw 和 vh 中**较小**的那个值。
- **vmax**: 取 vw 和 vh 中**较大**的那个值。

_适用场景：全屏背景、大屏可视化适配、响应式字号。_

### 容器相关 (其它)

- **% (百分比)**: 相对于**父元素**的对应属性。

  - 宽度的 % 是相对于父元素的宽度。

  - **注意**：`padding-top` / `padding-bottom` 设置百分比时，也是相对于父元素的**宽度**（不是高度）。

## 3. 常见对比

| 单位      | 参照物                 | 评价                                           |
| :-------- | :--------------------- | :--------------------------------------------- |
| **px**    | 屏幕像素               | 精准、稳定，但缺乏弹性。                       |
| **em**    | 父元素或自身字体       | 灵活但由于继承会导致计算复杂。                 |
| **rem**   | 根元素 (`<html>`) 字体 | **推荐**。兼具灵活性和可控性，响应式布局首选。 |
| **vw/vh** | 浏览器窗口视口         | 适合做大屏、全屏展示。                         |
