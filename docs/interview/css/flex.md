# flex

`flex: 1` 是一个复合属性，它让元素在 flex 容器中自动占据 **所有剩余空间**，是构建自适应布局最核心的 CSS 规则之一。

`flex: 1` 实际上是以下三个属性的缩写：

- flex-grow: 1
- flex-shrink: 1
- flex-basis: 0%

## 1. flex-grow: 1（放大比例）

- 定义：当 flex 容器内存在剩余空间时，此元素应该分配到多少比例的空间。
- 值为 1 的意义：占据所有可用的剩余空间。如果容器内有多个元素也设置了 flex-grow，它们会根据各自的值按比例瓜分剩余空间。

## 2. flex-shrink: 1（缩小比例）

- 定义：当 flex 容器的空间不足以容纳所有子元素时，此元素应该收缩多少比例。
- 值为 1 的意义：允许该元素收缩。默认值就是 1。如果设置为 0，则该元素不会收缩，可能会导致容器溢出。

## 3. flex-basis: 0%（基准尺寸）

- 定义：在分配剩余空间之前，浏览器计算的元素初始尺寸。
- 值为 0% 的意义：这是 flex: 1 中最关键也最容易被忽略的一点。它告诉浏览器，在计算空间分配时，不要考虑元素自身的原始宽度/高度（比如 content 的大小）。所有元素都从零开始，然后完全根据 flex-grow 的比例来瓜分整个父容器的空间。
- 对比 flex: auto (1 1 auto)：如果 flex-basis 是 auto，浏览器会先考虑元素自身内容的尺寸，然后再把剩下的剩余空间按比例分配。这会导致分配结果不完全符合 flex-grow 的比例。
