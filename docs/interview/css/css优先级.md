# CSS 优先级

| 优先级 | 选择器类型           | 权重 (简记法) | 示例                               | 备注                                            |
| ------ | -------------------- | ------------- | ---------------------------------- | ----------------------------------------------- |
| 1      | !important           | ∞ (最高)      | color: red !important;             | 慎用。它会覆盖以上所有权重，打破 CSS 级联规则。 |
| 2      | 行内样式 (Inline)    | "1,000"       | "<div style=""color: blue;"">"     | 直接写在 HTML 元素的 style 属性中。             |
| 3      | ID 选择器            | "0,100"       | "#header, #submit-btn"             | 每个 ID 在页面中应是唯一的。                    |
| 4      | 类、伪类、属性选择器 | "0,010"       | ".active, :hover, [type=""text""]" | 这种类型在开发中使用频率最高。                  |
| 5      | 元素、伪元素选择器   | "0,001"       | "div, p, ::before, span"           | 针对 HTML 标签本身。                            |
| 6      | 通配符、组合符、子选 | "0,000"       | "\*, >, +, ~"                      | 它们对权重没有任何贡献（加 0）。                |
| 7      | 继承 (Inherited)     | 无            | 比如子元素继承父元素的 font-family | 继承而来的样式权重最低，连 0 权重都打不过。     |

## 权重累加公式


1. A 级：内联样式 (Inline Style) —— (1, 0, 0, 0)

2. B 级：ID 选择器 —— (0, 1, 0, 0)

3. C 级：类、属性、伪类选择器 —— (0, 0, 1, 0)

4. D 级：标签、伪元素选择器 —— (0, 0, 0, 1)
