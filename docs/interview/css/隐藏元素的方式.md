# CSS 隐藏元素的方式

在 CSS 中隐藏元素有多种方式，它们在**视觉表现**、**空间占用**、**交互响应**以及**对 DOM 的影响**上都有所不同。

## 1. display: none

最彻底的隐藏方式。

- **表现**：元素从页面中彻底消失。
- **重排/重绘**：会触发 **Reflow (重排)** 和 Repaint (重绘)。
- **子元素**：所有子元素也会被隐藏，且无法通过给子元素设置 `display: block` 来显示。

## 2. visibility: hidden

“隐身”效果。

- **表现**：元素看不见，但还在原来的位置。
- **交互**：无法点击（鼠标事件不会触发）。
- **重排/重绘**：只触发 **Repaint (重绘)**，因为布局没变。
- **子元素**：子元素继承隐藏。**但**如果给子元素设置 `visibility: visible`，子元素**可以显示**出来！

## 3. opacity: 0

透明度设为 0。

- **表现**：元素完全透明。
- **空间占用**：**占据**空间。
- **交互**：**可以点击**，可以触发事件！
- **重排/重绘**：如果不改变 layout，只触发 Repaint（通常结合 GPU 加速）。
- **子元素**：子元素也透明，无法单独显示。

## 4. position: absolute (移出可视区)

把元素扔到屏幕外面去。

- **表现**：屏幕内看不见。
- **空间占用**：不影响主体文档流（因为脱离了文档流），但理论上它还在 DOM 树里渲染。
- **交互**：看不见所以点不到，但键盘 Tab 键可能还能切到。
- **场景**：常用于 seo 优化（比如隐藏的文字标签）。

```css
.hide {
  position: absolute;
  left: -9999px;
  top: -9999px;
}
```

## 5. z-index: -999

把元素藏在其他元素底下。

- **表现**：被其他层盖住了。
- **空间占用**：占据空间。
- **交互**：点不到（因为被挡住了）。

```css
.hide {
  position: relative;
  z-index: -999;
}
```

## 6. height: 0 + overflow: hidden

- **表现**：类似折叠起来了。
- **空间占用**：如果是 block 元素，高度为 0，但 border/margin 可能还在。
- **交互**：无法点击。
- **场景**：常用作手风琴动画效果。

```css
.hide {
  height: 0;
  overflow: hidden;
}
```

---

## 总结对比表

| 方式                   | 占据空间? | 能点击交互? | 触发重排(Reflow)? | 子元素可复原?   | 备注                     |
| :--------------------- | :-------- | :---------- | :---------------- | :-------------- | :----------------------- |
| **display: none**      | ❌ (无)   | ❌          | ✅ (高开销)       | ❌              | 最常用的彻底隐藏         |
| **visibility: hidden** | ✅ (有)   | ❌          | ❌ (仅重绘)       | ✅ (可 visible) | 占坑位，子元素可救       |
| **opacity: 0**         | ✅ (有)   | ✅ (能!)    | ❌ (仅重绘)       | ❌              | 仅仅是看不见，还得防误触 |
| **position: absolute** | ❌ (脱离) | ❌          | ✅                | ❌              | 这种叫“移走”更合适       |
