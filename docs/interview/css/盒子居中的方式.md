# 盒子居中的方式

## 1. Flexbox (弹性布局)

- **原理**：利用 flex 容器的主轴和交叉轴对齐属性。

```css
.container {
  display: flex;
  justify-content: center; /* 水平居中 (主轴) */
  align-items: center; /* 垂直居中 (交叉轴) */
}
```

## 2. Grid (网格布局)

- **原理**：`place-items` 是 `justify-items` 和 `align-items` 的简写。

```css
.container {
  display: grid;
  place-items: center;
}
```

## 3. 绝对定位 + Transform

- **缺点**：脱离文档流。

```css
.container {
  position: relative;
}
.box {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

## 4. 绝对定位 + Margin: auto

- **强制要求**：子元素**必须有固定的宽高**，否则会拉伸填满。

```css
.container {
  position: relative;
}
.box {
  position: absolute;
  top: 0;
  left: 0;
  right: 0;
  bottom: 0;
  margin: auto;

  width: 100px; /* 必须定宽 */
  height: 100px; /* 必须定高 */
}
```

## 5. 仅水平居中

### Block 元素 (如 div)

```css
.box {
  margin: 0 auto;
  width: 200px; /* 必须有宽度 */
}
```

### Inline 元素 (如 text, span, img)

```css
.container {
  text-align: center;
}
```
