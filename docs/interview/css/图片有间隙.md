# 图片有间隙

当你把一张图片放进一个 `div` 容器时，经常会发现图片底部（有时是左右侧）出现了莫名的空白间隙。

### 一、 `vertical-align` 是什么属性？

`vertical-align` 是用来指定 **行内元素（inline）**、**行内块级元素（inline-block）** 或 **表格单元格（table-cell）** 在垂直方向上的对齐方式的属性。

- **它的默认值是 `baseline`（基线对齐）。**
- **适用范围**：它对块级元素（`display: block`）是无效的。

### 二、 图片为什么会有间隙？

**1. 底部间隙的原因（最常见）：**

`<img>` 标签在 CSS 中默认是一个行内替换元素。

它的默认垂直对齐方式是 `vertical-align: baseline`，浏览器在渲染它时，会把它和周围的文本文字的“基线”对齐。

**2. 左右间隙的原因：**

如果你在一行写了多个 `<img>` 标签，并且在 HTML 代码中它们之间有换行或空格，浏览器会将这些换行/空格解析为一个**空格字符**。由于图片是行内元素，这个空格就会占据一定的宽度，表现为图片左右之间的间隙。

### 三、 如何解决图片间隙？

#### 方案 A：改变图片的垂直对齐方式（解决底部间隙）

既然默认的 `baseline` 会留出底边距，我们把它改成其他对齐方式即可。既保留了图片的行内特性，又去掉了缝隙。

```css
img {
  vertical-align: middle; /* 或者 top, bottom 都可以 */
}
```

#### 方案 B：将图片变成块级元素（解决底部间隙）

块级元素不存在所谓的“基线对齐”问题。如果你的图片本身就是独占一行的，直接把它变成块级元素是最干脆的做法。

```css
img {
  display: block;
}
```

#### 方案 C：将父元素的字体大小设为 0（同时解决底部和左右间隙）

由于间隙本质上是为“文本”留出的空间或空格字符，如果文本的大小变成了 0，间隙自然就消失了。

```css
.img-container {
  font-size: 0;
}
```

_(注意：如果父容器里除了图片还有真正的文字，文字也会消失，所以此方法仅适用于纯图片容器。)_

#### 方案 D：使用 Flex 布局（现代且万能）

给图片的父容器开启 Flexbox，可以直接消除掉所有的文本基线问题和空格间隙。

```css
.img-container {
  display: flex;
}
```

**总结建议：**
如果你只是想单纯地去掉单张图片底部的白边，直接给图片加上 `display: block;` 或 `vertical-align: middle;` 就可以了。如果是多张图片拼图（不想有任何缝隙），建议用 `display: flex;` 加在父元素上。
