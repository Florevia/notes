# css 预处理和后处理器

CSS 预处理器和后处理器都是为了弥补 **原生 CSS 的不足、提高开发效率和代码可维护性** 而诞生的工具。

> 预处理器让你写 CSS 更爽，后处理器让你的 CSS 更兼容、更精简。

## 预处理器

预处理器提供了一种新的、扩展的 CSS 语法，允许你使用变量、嵌套规则、混合（Mixin）、函数等特性，使 CSS 代码更加清晰、易维护。

### 主要功能：

- 变量 (Variables)：统一管理颜色、字体大小等，一处修改，全局生效。

- 嵌套 (Nesting)：允许在父选择器内部编写子选择器，代码结构与 HTML 结构高度一致，避免重复书写父级类名。

- 混合 (Mixins)：将一组属性打包，像函数一样在其他地方反复调用。

- 继承 (Extend)：让一个选择器继承另一个选择器的所有样式。

- 数学运算和逻辑控制：支持加减乘除、if/else 条件判断、for 循环等。

### 主流代表：

- Sass / SCSS（目前最流行，功能最强大，Vue/React 项目标配）

- Less（基于 Node.js，语法较 Sass 简单，常用于 Ant Design 等组件库）

- Stylus（语法极其极简，可以省略花括号和冒号）

## 后处理器

### 主要功能：

- 自动添加浏览器前缀 (Autoprefixing)：你只需要写标准属性（如 display: flex;），工具会自动帮你补全 -webkit-、-moz- 等前缀，以兼容旧版浏览器。

- 代码压缩 (Minification)：移除空格、注释，合并相同的选择器，减小文件体积（如 cssnano）。

- 语法降级 (Polyfill)：允许你提前使用未来版本的 CSS 新特性，工具会将其转换成当前浏览器支持的旧语法（如 postcss-preset-env）。

- 代码检查 (Linting)：检查 CSS 语法是否符合规范，避免低级错误（如 stylelint）。

### 主流代表：

- PostCSS（它是后处理器领域的绝对霸主，本身只提供解析框架，所有功能都由生态中的插件实现，比如最著名的 Autoprefixer 插件）。
