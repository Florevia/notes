# 对比

> 误区：Tailwind CSS 的 Utility Classes（原子类）并不等于行内样式（Inline Styles）

## Tailwind CSS 优点

1. 减少了 命名心智负担，并且不需要在html和css文件之间跳来跳去。

2. 手写 CSS 时，CSS 体积的对数级增长， 但原子类是复用的，CSS 产物的体积增长会迅速趋于平缓，通常最终压缩后仅有 10KB - 50KB。

3. 局部作用域，无全局污染。便于维护。

4. 强制性的设计约束，Tailwind 默认的缩放系统（如 p-4 代表 1rem）保证了 UI 的高度一致性，减少了视觉还原误差。

## 结合 AI 趋势的补充视角

1. AI 的上下文理解更好：AI 看到 HTML 结构和 Tailwind 类名，就能完全理解这个组件长什么样，不需要跨文件去读取 CSS 定义。

2. 生成速度极快。
