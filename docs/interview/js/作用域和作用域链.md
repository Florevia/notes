# 作用域和作用域链

## 1. 作用域 (Scope)

**作用域** 简单来说就是 **变量的可访问范围**。它规定了在什么地方可以访问到哪些变量。

> 掌握闭包（Closure）和 this 机制的前提

JavaScript 采用的是 **词法作用域 (Lexical Scope)**，也称为 **静态作用域**。

> 函数的执行作用域在 **函数定义的时候就已经决定了**，而不是在函数调用的时候。

### 三种主要作用域

1.  **全局作用域 (Global Scope)**

    - 在代码最外层定义的变量。
    - 在任何地方都能访问。
    - 生命周期伴随页面生命周期（关闭页面才销毁）。

2.  **函数作用域 (Function Scope)**

    - 在函数内部定义的变量。
    - 只能在函数内部访问，外部无法访问。
    - 函数执行完后，内部变量通常会被销毁（除非有闭包）。

3.  **块级作用域 (Block Scope) [ES6+]**
    - 使用 `let` 或 `const` 在 `{}` (代码块) 中定义的变量。
    - `if`、`for`、`while` 的大括号都会形成块级作用域。
    - `var` 定义的变量 **没有** 块级作用域。

## 2. 作用域链 (Scope Chain)

当 JS 引擎在一个作用域中查找变量时，如果自己的作用域没有，它会去 **父级作用域** 找。如果父级也没，就去父级的父级... 直到全局作用域。

> 这条 **由内向外** 的查找路径，就是 **作用域链**。

### 核心规则：词法作用域

父级作用域是谁，取决于 **函数是在哪声明的**，而不是在哪调用的。

#### 经典案例解析

```js
var a = 100;

function dad() {
  var a = 200;

  // son 是在 dad 内部声明的
  // 所以 son 的父级就是 dad
  function son() {
    console.log(a);
  }

  return son;
}

var anotherCousin = dad();
anotherCousin(); // 输出 200
```

#### 迷惑性案例（区别于动态作用域）

```js
var x = 10;

function fn() {
  console.log(x);
}

function show(f) {
  var x = 20;
  // 虽然是在 show 里面调用了 f
  // 但 f 是在全局声明的！
  // 所以 f 的父级是全局作用域
  (function () {
    f(); // 10，而不是 20
  })();
}

show(fn);
```

## 3. 自由变量 (Free Variable)

- **定义**：在当前作用域中 **使用** 了，但 **没有在当前作用域中声明** 的变量。

- 自由变量的存在是 **闭包（Closure）** 形成的根本原因。闭包本质上就是“函数 + 该函数引用的自由变量”

```js
var a = 100;
function fn() {
  var b = 200;
  console.log(a); // a 在这里就是“自由变量”
  console.log(b);
}
```

## 4. 作用域 vs 执行上下文

这是一个容易混淆的深层概念：

| 维度         | 作用域 (Scope)                 | 执行上下文 (Execution Context)  |
| :----------- | :----------------------------- | :------------------------------ |
| **性质**     | **静态**的                     | **动态**的                      |
| **产生时间** | 函数 **定义** 时就确定了       | 函数 **调用** 时才创建          |
| **生命周期** | 代码写完就在那了，不随调用改变 | 调用结束通常会被销毁 (除非闭包) |

**总结关系**：

- **执行上下文** 是一个运行时的环境 (包含 `VO/AO`、`this` 等)。
- **作用域** (具体说是作用域链) 是执行上下文中的一个属性 (用于查找变量的规则)。
- **执行上下文在创建时，会去利用已经定义好的『作用域规则』来生成自己的作用域链。**
