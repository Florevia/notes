# 数组常用方法

## 1. 改变原数组的方法

- `push(item)` / `pop()`：尾部追加 / 尾部删除。

- `unshift(item)` / `shift()`：头部添加 / 头部删除

  > 性能：比 `push/pop` 慢，因为要移动所有元素下标。

- `splice(start, deleteCount, ...items)`：增、删、改全能。

  > `splice(1, 1)`: 删除第 2 个。
  > `splice(1, 0, 'a')`: 在第 2 个位置插入 'a'。

  > 返回：被删除的元素数组。

- `reverse()`：反转数组。

- `sort()`：排序

  > 默认行为：排字符串 (按 ASCII 码)

  > 排字母：

  ```javascript
  ["e", "a", "t"].sort(); // ['a', 'e', 't']
  ```

- 注意：排数字时

  > 因为默认转字符串，所以 "10" 会排在 "2" 前面（因为字符 '1' 比 '2' 小）。

  ```javascript
  [10, 2, 5].sort(); // [10, 2, 5] (这通常不是你想要的！)
  ```

- 排数字 (需传入比较函数)

要正确排数字，必须传入一个函数 `(a, b) => a - b`。

- 升序 (小 -> 大)：

  ```javascript
  [10, 2, 5].sort((a, b) => a - b); // [2, 5, 10]
  ```

- **降序 (大 -> 小)**：

  ```javascript
  [10, 2, 5].sort((a, b) => b - a); // [10, 5, 2]
  ```

- 排对象数组 (按某个属性排)

在实际开发中，我们经常需要排一堆对象（比如按这群人的年龄排序）。

```javascript
const users = [
  { name: "Li", age: 30 },
  { name: "Wang", age: 18 },
];

// 按 age 升序排
users.sort((a, b) => a.age - b.age);
// 结果：Wang (18) 在前，Li (30) 在后
```

- 排中文 (拼音排序)

如果要排中文字符串，直接 `sort()` 可能会乱（它是按 Unicode 编码排的）。可以使用 `localeCompare`。

```javascript
["张三", "李四", "王五"].sort((a, b) => a.localeCompare(b, "zh"));
// ['李四', '王五', '张三'] (按拼音 l, w, z 排序)
```

## 2. 不改变原数组的方法

- `slice(start, end)`：切片，含头不含尾 `[start, end)`。

- `concat(...arrays)`：合并数组。现多用扩展运算符 `[...a, ...b]` 替代。

- `join(separator)`：数组转字符串。默认逗号分隔。

## 3. 遍历与转换

- `forEach(callback)`：单纯遍历，没有返回值（undefined）。**不能**被 `break` 打断。

- `map(callback)`：映射。返回一个新数组，长度和原数组一致。

- `filter(callback)`：过滤。返回一个新数组，包含所有返回 true 的元素。

- `reduce(callback, initialValue)`：将数组“归约”为一个值（求和、去重、统计）。

## 4. 查找与检测

- `indexOf(item)`: 找下标，找不到返回 -1。
- `includes(item)`: 是否包含，返回 true 或 false。
- `find`: 找第一个满足条件的元素，没找到返回undefined。
- `findIndex`: 找第一个满足条件的元素的下标，没找到返回-1。
- `some`: 只要有一个满足条件就返回 true。
- `every`: 必须所有都满足条件才返回 true。
