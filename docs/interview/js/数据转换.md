# 数据转换

## 显式转换

### Number()

底层调用 ToNumber()

#### 原始数据类型转数字

| 原始值      | 转换结果                                             |
| :---------- | :--------------------------------------------------- |
| `undefined` | `NaN`                                                |
| `null`      | `0`                                                  |
| `boolean`   | `true` → 1, `false` → 0                              |
| `string`    | 纯数字 → 数字<br>空串/空白符 → 0<br>含非数字 → `NaN` |

#### 对象转成数字

1. 检查 `Symbol.toPrimitive`：

   如果有该方法，调用它并传入 hint 为 "number"。如果返回原始值，则结束；否则报错。

2. 调用 `valueOf()`：

   如果返回的是 **原始类型**，则对该值进行 **ToNumber()** 转换并返回。

3. 调用 `toString()`：

   如果 `valueOf` 返回的不是原始值，则尝试调用 `toString`。如果返回原始值，则对该值进行 **ToNumber()** 转换。

```js
const obj = {
  a: 1,
  name: "lilin",
};
console.log(obj.valueOf());
console.log(obj.toString());
console.log(Number(obj));
```

4. 报错：

   如果 `toString` 返回的还不是原始值，抛出 TypeError。

#### parseInt() / parseFloat()

它们与 `Number()` 的核心区别在于：**宽松解析**。

1. **从左到右解析**：会自动逐个字符读取，直到遇到无法解析的字符为止。
2. **忽略后续字符**：一旦遇到非法字符，立即停止并返回前面的数字。

```js
console.log(Number("123px")); // NaN (严格，只要有一个非法字符就挂)

console.log(parseInt("123px")); // 123 (读到 'p' 停下)

console.log(parseInt("abc123")); // NaN

console.log(parseFloat("12.5em")); // 12.5
```

### String()

底层调用 ToPrimitive()

#### 原始数据类型转字符串

| 原始值      | 转换结果                           |
| :---------- | :--------------------------------- |
| `undefined` | `"undefined"`                      |
| `null`      | `"null"`                           |
| `boolean`   | `true` → "true"、`false` → "false" |
| `string`    | `"string"`                         |
| `number`    | `123` → "123"                      |

#### 对象转成字符串

1. 检查 `Symbol.toPrimitive`：

   - 调用它并传入 hint 为 "string"。
   - 如果返回原始值，结束；否则报错。

2. 调用 `toString()`：

   - 优先调用 `toString`。如果返回 **原始值**，结束。
   - 普通对象 `{}` 的 `toString` 默认返回 "[object Object]"。
   - 数组 `[1, 2]` 的 `toString` 默认返回 "1,2"。

3. 调用 `valueOf()`：

   - 如果 `toString` 失败（返回对象），才去调用 `valueOf`。

4. 报错：

   - 如果在这一步还拿不到原始值，抛出 TypeError。

```js
const obj = {
  a: 1,
  name: "lilin",
};
console.log(obj.toString()); // [object Object]
console.log(obj.valueOf()); // { a: 1, name: 'lilin' }
console.log(String(obj)); // [object Object]
```

### Boolean()

只要不是以下 6 个假值（Falsy），结果全是 true：

- `undefined`
- `null`
- `false`
- `0` (包括 +0, -0)
- `NaN`
- `""` (空字符串)

特别注意：

- `Boolean([]) ➔ true`
- `Boolean({}) ➔ true`
- `Boolean(new Boolean(false)) ➔ true` (因为它是对象)

## 隐式转换

- 四则运算：

  - `+ 号` 较为特殊：只要有一侧是字符串，就执行字符串拼接；否则转为数字进行加法。

  - `- * / %`：一律转为数字进行运算。

- 逻辑判断：

  - `if`、`while`、`!` (取反)、`&&`、`||` 会自动转为 `Boolean`。

- 宽松相等 (==)：

  - `null == undefined` 为 `true`（且它们不等于其他任何值）。

  - 如果类型不同，通常是先转数字再比较（例如 `true == 1` 为 `true`）。

  - 如果是对象和原始值比较，对象会先转换为原始值。

```js
console.log({} == true); // false
```
