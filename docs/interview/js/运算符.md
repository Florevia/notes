# 运算符 (Operators)

## 1. 算术运算符

- `+` 的特殊性：只要有一侧是字符串，就执行 **拼接**；否则执行 **加法**。

  ```js
  1 + "1"; // "11"
  true + true; // 2 (true 转为 1)
  1 + {}; // "1[object Object]"
  ```

- `++` / `--`：

  - `a++`：先用，再加。
  - `++a`：先加，再用。

  ```js
  let a = 1;
  console.log(a++); // 1
  console.log(++a); // 3
  ```

## 2. 比较运算符

### `==` (宽松相等)：会发生 **隐式类型转换** 再比较。

1. 并没有通过转换：null 与 undefined

```js
null == undefined; // true
null == 0; // false
undefined == 0; // false
```

2. 只有一侧是 String，另一侧是 Number

   String 转 Number 再比较。

```js
"1" == 1;
// true  -> 1 == 1

"" == 0;
// true  -> 0 == 0

"1a" == 1;
// false -> NaN == 1
```

3. Boolean 参与比较

   Boolean 最“低微”，只要看到它，立马转 Number（true 变 1，false 变 0），然后再进行下一轮比较。

```js
[] == ![]; // true (面试经典题)

true == "1";
// (步骤: true变1 -> 1=="1" -> "1"变1 -> 1==1) -> true

false == "0";
// (步骤: false变0 -> 0=="0" -> "0"变0 -> 0==0) -> true

true == 2;
// (步骤: true变1 -> 1==2) -> false
```

4.  Object 与 非 Object 比较

    Object 尝试 转基本类型 (ToPrimitive)（先调 valueOf，不行再调 toString），然后再比较。

```js
[1] == 1
// ([1]变"1" -> "1"==1 -> 1==1) -> true

[] == 0
// ([]变"" -> ""==0 -> 0==0) -> true

{} == "[object Object]"
// true ({}变"[object Object]")
```

### `===` (严格相等)

类型不同直接 `false`。**推荐始终使用 `===`**。

### `Object.is(v1, v2)`

基本同 `===`，但修复了两个特殊值：

- `Object.is(NaN, NaN)` ➔ `true`
- `Object.is(+0, -0)` ➔ `false`

## 3. 逻辑运算符 (短路机制)

- `&&` (与)：**全真才真**。即使第一个是 `false`，也会返回第一个（短路）。

  - 取值规则：找到第一个假值并返回；若全真，返回最后一个值。

  ```js
  const a = 1 && "hello"; // "hello"
  const b = 0 && "hello"; // 0
  ```

- `||` (或)：**一真即真**。

  - 取值规则：找到第一个真值并返回；若全假，返回最后一个值。

  ```js
  const name = user.name || "Default";
  ```

- `!` (非)：强转布尔并取反。
  - `!!value`：常用技巧，将值转为布尔类型。

## 4. 赋值与一元运算符

- 赋值：`=`, `+=`, `-=`, `*=`, `/=` 等。
- 一元正号 `+`：将操作数转换为数字。

  ```js
  +"123"; // 123
  ```

## 5. ES2020+ 新运算符

- `?.` (可选链 Optional Chaining)：
  安全访问深层属性，若中间断链（null/undefined）则返回 undefined，不会报错。

  ```js
  const city = user?.address?.city;
  ```

- `??` (空值合并 Nullish Coalescing)：
  只有当左侧是 `null` 或 `undefined` 时，才返回右侧。
  （区别于 `||`，`||` 会把 `0` 或 `""` 也视为假值）。
  ```js
  const count = 0 ?? 100; // 0
  const num = 0 || 100; // 100
  ```
