# 闭包

## 基本概念

在 js 中，闭包是指一个函数以及其捆绑的词法环境的组合。通俗地讲，闭包使得内部函数即使在外部函数执行完毕并出栈后，依然能够访问并操作外部函数作用域中的变量。

## 底层原理

闭包的产生依赖于 js 的 **词法作用域和作用域链** 机制

- 词法作用域（Lexical Scoping）： 函数的作用域在定义时就已经确定了，而不是在调用时。

- 作用域链（Scope Chain）： 当内部函数访问变量时，会先在其自身作用域查找。如果找不到，就会去外层作用域查找，直到全局作用域。

## 经典面试题

```js
for (var i = 1; i <= 3; i++) {
  setTimeout(function () {
    console.log(i);
  }, 1000);
}
// 结果：输出 3 次 4
```

```js
for (let i = 1; i <= 3; i++) {
  setTimeout(function () {
    console.log(i);
  }, 1000);
}
// 结果：输出 1, 2, 3
```

1. 使用 `var` 时，`i` 是全局共享的，循环结束后 `i` 变成了 4，异步执行的 `setTimeout` 读取的都是同一个最终值。

2. 使用 `let` 时，利用了 **块级作用域**。JS 会在每次循环迭代中为 `i` 创建一个 **新的词法环境** 。**每个 `setTimeout` 的闭包都捕获了当前迭代那个独立的 `i`**，互不干扰，所以能输出正确的结果。

## 面试：什么是闭包？

1. 概念
   - MDN 对它的解释：闭包（Closure）就是 **函数 + 其定义时的词法环境的组合**。

   - 当一个函数在离开其定义处后被调用时，仍能访问外层作用域中的变量。
     > **函数能够访问它定义时的作用域**，即使在它的外部环境已经执行完毕

2. 作用
   - 做数据私有化与封装状态（不暴露到全局）
   - 事件/异步回调中继续使用当时的上下文

3. 常见场景
   - 计数器/权限控制
   - 按钮点击携带参数
   - 防抖节流，利用闭包保存 timer 变量，确保同一时间段内状态的唯一性。

4. 注意点
   - for + var 导致共享同一绑定
   - 内存泄漏（及时清理监听/计时器）：将引用的函数设置为 null

### 手写闭包

```js
function createCounter() {
  let count = 0;
  return function () {
    count++;
    return count;
  };
}

let increase = createCounter();
console.log(increase()); // 1
console.log(increase()); // 2
```

```js
function myFn() {
  let a = 1;
  return function () {
    console.log(a);
  };
}

let fn = myFn();
fn(); // 1
```
