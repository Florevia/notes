# 字符串常用方法

字符串在 JS 中是 **不可变 (Immutable)** 的，这意味着字符串上的所有“修改”操作（如 replace, slice, trim）都不会改变原字符串，而是 **返回一个新的字符串**。

## 1. 增删改 (CRUD) - 伪概念

由于字符串不可变，我们只能通过返回新字符串来模拟“增删改”。

### **`concat(str2, str3...)`**

- 作用：拼接字符串。
- 推荐：日常开发更推荐用 `+` 运算符或 **模板字符串** `${a}${b}`。

### **`slice(start, end)`** (⭐⭐⭐)

- 作用：提取子字符串。
- 特点：含头不含尾 `[start, end)`。支持负数索引（倒数第几个）。
- 示例：`'hello'.slice(0, 2) // 'he'`

### **`substring(start, end)`**

- 作用：提取子字符串。
- 区别：不支持负数（负数会被当做 0）。如果不涉及负数，和 slice 差不多。

### **`padEnd(length, padChar)` / `padStart(length, padChar)`**

- 作用：在尾部/头部补全字符直到指定长度。
- 场景：时间格式化（`'5'.padStart(2, '0')` -> `'05'`）。

### **`trim()`** / `trimStart()` / `trimEnd()`

- 作用：去除空白符（空格、换行等）。

## 2. 查 (Query)

### **`indexOf(str)`** / `lastIndexOf(str)`

- 作用：查找子串位置。找不到返回 -1。
- 场景：简单的存在性检查。

### **`includes(str)`** (ES6 ⭐⭐⭐)

- 作用：判断是否包含子串。返回 Boolean。
- 场景：替代 `indexOf() !== -1`，语义更清晰。

### **`startsWith(str)`** / `endsWith(str)` (ES6)

- 作用：判断是否以 xxx 开头/结尾。

### **`charAt(index)`**

- 作用：获取指定位置字符。等价于 `str[index]`。

## 3. 转换

### **`split(separator)`** (⭐⭐⭐)

- 作用：字符串 -> 数组。
- 场景：`'a,b,c'.split(',')` -> `['a', 'b', 'c']`。

### **`toLowerCase()`** / `toUpperCase()`

- 作用：大小写转换。

## 4. 正则匹配与替换 (RegExp)

### **`replace(search, replace)`**

- 作用：替换。
- 注意：如果 `search` 是字符串，**只替换第一个**！想替换所有，必须配合正则 `/g` 或使用 `replaceAll`。

### **`replaceAll(search, replace)`** (ES2021)

- 作用：替换所有匹配项。
- 场景：`'a-b-c'.replaceAll('-', '_')` -> `'a_b_c'`。
