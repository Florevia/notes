# 原型和原型链

## 核心概念三件套

### 1. 原型对象 (Prototype Object)

> 原型是实现继承和属性共享的核心机制

#### 显式原型 (`prototype`)

- 每一个函数（除箭头函数外）都有一个 `prototype` 属性。

- 这个属性指向一个对象，这个对象就是通过该构造函数创建的所有实例的公共祖先。

- 作用：通用的方法挂载到构造函数的 `prototype` 上，以减少内存消耗，实现复用。

#### 隐式原型 `__proto__` 、 `[[Prototype]]`

- **每个对象** (Object)（除了 null）都有这个属性。

- 作用：它指向创建该对象的构造函数的 `prototype`。

- **本质**：它是连接“原型链”的桥梁。

#### 构造函数 (Constructor)

- 原型对象有一个 `constructor` 属性，指向该构造函数本身。
- `Person.prototype.constructor === Person`

## 原型链 (Prototype Chain)

当访问一个对象的属性时：

1.  先在 **对象自身** 查找。
2.  如果没有，就会沿着 `__proto__` 去它的 **原型对象** 中查找。
3.  如果还没找到，就去 **原型对象的原型** (`Object.prototype`) 中查找。
4.  直到找到 `Object.prototype.__proto__` 为止（结果是 `null`）。

这条由 `__proto__` 串起来的链条，就是 **原型链**。

## 关键面试题

### 1. `instanceof` 的原理

`instanceof` 并不检查类型，它是检查 **右边构造函数的 `prototype` 是否出现在左边实例的原型链上**。

```js
function myInstanceof(left, right) {
  let proto = Object.getPrototypeOf(left); // 获取左侧的隐式原型
  let prototype = right.prototype; // 获取右侧的显式原型

  while (true) {
    if (!proto) return false; // 走到尽头 null 了
    if (proto === prototype) return true; // 找到了
    proto = Object.getPrototypeOf(proto); // 继续往上找
  }
}
```

### 2/. Function 和 Object 的鸡生蛋问题

- `Function.__proto__ === Function.prototype` (Function 是它自己生的)
- `Object.__proto__ === Function.prototype` (Object 构造函数也是函数，也是 Function 生的)
- `Function.prototype.__proto__ === Object.prototype` (Function 的原型也是个对象，是 Object 生的)

**总结**：一切函数都由 Function 创建，一切对象都由 Object 创建（指原型链顶端）。
