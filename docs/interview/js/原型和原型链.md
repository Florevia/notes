# 原型和原型链

## 核心概念三件套

> 原型是实现继承和属性共享的核心机制

### 显式原型 (`prototype`)

- 每一个函数（构造函数/类）（除箭头函数外）都有一个 `prototype` 属性。

- 它是一个对象，用来存放子类（实例）共享的属性和方法。

- 作用：通用的方法挂载到构造函数的 `prototype` 上，以减少内存消耗，实现复用。

### 隐式原型 `__proto__` 、 `[[Prototype]]`

- 所有对象，包括实例、函数、数组（除了null）。

- 作用：它指向创建该对象的构造函数的 `prototype`。

- **本质**：它是连接“原型链”的桥梁。

### 构造器 (Constructor)

- 原型对象（prototype）有一个 `constructor` 属性，指向该构造函数本身。
- `Person.prototype.constructor === Person`

```js
// 实例的隐式原型 === 构造函数的显式原型
instance.__proto__ === Constructor.prototype;
```

## 原型链 (Prototype Chain)

原型链本质上就是 **对象属性的查找机制**

当你访问一个对象的属性时：js 引擎会按照以下步骤查找：

- **自身查找**： 先看对象自身有没有这个属性？如果有，直接返回。

- **向上查找**： 如果自身没有，就顺着 `__proto__` 去它的原型对象里找。

- **层层递进**： 如果原型对象里还没有，就继续顺着原型的 `__proto__` 找原型的原型。

- **终点**： 一直找到最顶层的 `Object.prototype`。如果这里还没有，再往上找就是 `null`。此时返回 `undefined`。

这条由 **proto** 串联起来的链条，就叫做原型链。

## 常见面试题

### 1. Function 和 Object 的鸡生蛋问题

- `Function.__proto__ === Function.prototype` (Function 是它自己生的)
- `Object.__proto__ === Function.prototype` (Object 构造函数也是函数，也是 Function 生的)
- `Function.prototype.__proto__ === Object.prototype` (Function 的原型也是个对象，是 Object 生的)

> **总结**：一切函数都由 Function 创建，一切对象都由 Object 创建（指原型链顶端）。

### new 操作符做了什么？(手写 new 经常考)

简单概括为 4 步（每一号位都跟原型有关）：

1. 创建这个新对象 obj。

2. 关键： 将 `obj.__proto__` 链接到构造函数的 `prototype`。

3. 执行构造函数，将 this 绑定到 obj。

4. 返回这个对象。

```js
/**
 * 手写 new 操作符
 * @param {Function} Constructor 构造函数
 * @param {...any} args 构造函数的参数
 */
function myNew(Constructor, ...args) {
  // 1. 创建一个新对象
  // 2. 将新对象的隐式原型(__proto__)链接到构造函数的显式原型(prototype)
  // 这里的 Object.create() 一步到位完成了前两步
  const obj = Object.create(Constructor.prototype);

  // 3. 执行构造函数，并将 this 绑定到新对象上
  // 使用 apply 把 args 数组传进去
  const result = Constructor.apply(obj, args);

  // 4. 返回值处理 (最重要的细节！)
  // 如果构造函数显式返回了一个对象(或函数)，则返回该结果；
  // 否则（返回基本类型或无返回），返回我们需要的新对象 obj。
  if (
    (typeof result === "object" && result !== null) ||
    typeof result === "function"
  ) {
    return result;
  }

  return obj;
}
```

c测试用例：

```js
// --- 测试用例 1: 正常情况 ---
function Person(name, age) {
  this.name = name;
  this.age = age;
}
Person.prototype.sayHi = function () {
  console.log("Hi, I am " + this.name);
};

const p1 = myNew(Person, "Tom", 18);
console.log(p1.name); // "Tom"
p1.sayHi(); // "Hi, I am Tom"
console.log(p1 instanceof Person); // true

// --- 测试用例 2: 构造函数返回对象 (陷阱) ---
function Student(name) {
  this.name = name;
  // 显式返回一个对象
  return { type: "Student Object" };
}

const s1 = myNew(Student, "Jerry");
console.log(s1.name); // undefined
console.log(s1.type); // "Student Object" (返回了 return 的对象，而不是 s1 实例)
```
