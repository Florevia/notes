# Node.js 模块判断逻辑

Node.js 决定一个文件是 **ES Module (ESM)** 还是 **CommonJS (CJS)** 的判定流程如下：

## 优先级总结

1.  **强制扩展名 (最高优先级)**

    - `.mjs` 永远是 ESM。
    - `.cjs` 永远是 CommonJS。

2.  **`package.json` 控制**

    - 如果扩展名是 `.js`，则查看最近的 `package.json` 中的 `type` 字段。
    - `"type": "module"` ➔ ESM。
    - `"type": "commonjs"` (或不写) ➔ CommonJS。

3.  **语法探测 (实验性)**
    - 如果 `.js` 文件且 `package.json` 未指定 `type`。
    - 默认情况下，Node.js 会将其视为 CommonJS。
    - 如果开启了 `--experimental-detect-module` 标志，Node.js 会探测文件内容：
      - 如果有 `import` / `export` 语法 ➔ ESM。
      - 否则 ➔ CommonJS。
