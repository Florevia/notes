# 深拷贝与浅拷贝

## 浅拷贝

### 原理

只复制对象的第一层属性。

- 如果属性是基本类型，拷贝的是值；
- 如果属性是引用类型（对象/数组），拷贝的是内存地址（指针）。修改新对象中的引用类型数据，会影响原对象。

### 实现

#### Object.assign(target, ...sources)

- 作用：将所有可枚举的自有属性从一个或多个源对象复制到目标对象，并返回目标对象。

- 语法：`Object.assign(target, ...sources)`
  - `target` (目标对象)
    - 所有源对象的属性都会被复制到这个对象上。
    - 这个对象会被修改（副作用）。
    - 函数最终会返回这个对象。
  - `...sources` (源对象)
    - 可选（一个或多个）。
    - 你要从中复制属性的对象。
    - 只有 可枚举 (enumerable) 且 自有 (own) 的属性会被复制。
    - 如果源对象是 null 或 undefined，它会被忽略，不会报错。

- 代码：

  ```js
  const original = { name: "Li", age: 18 };
  // 相当于把 original 所有的属性复制到一个全新的空对象里
  const copy = Object.assign({}, original);
  ```

  如果源对象的属性值是一个指向对象的引用，它只拷贝那个引用值（内存地址）。

  ```js
  const obj = {
    a: 1,
    b: { c: 2 }, // b 是个对象
  };

  const copy = Object.assign({}, obj);

  copy.b.c = 999;
  console.log(obj.b.c); // 999 -> 原对象也被改了！因为 b 只是拷贝了地址。
  ```

  如果多个源对象有同名属性，后面的会覆盖前面的。

  ```js
  Object.assign({}, { a: 1 }, { a: 2 }); // { a: 2 }
  ```

#### ES6 扩展运算符

```js
const original = { a: 1, b: 2 };

// 浅拷贝
const copy = { ...original };
// 等同于 Object.assign({}, original)

console.log(copy); // { a: 1, b: 2 }
console.log(copy === original); // false (内存地址变了)
```

如果属性值是对象，拷贝的依然是引用（内存地址）。

```js
const obj = {
  a: 1,
  b: { c: 2 }, // b 是个对象
};

const copy = { ...obj };

console.log(copy.b === obj.b); // true -> 拷贝的还是地址
```

#### 数组方法

##### `Array.prototype.slice() `

- slice 本意是“切片”，如果不传参数，就是从头切到尾。

```js
const arr = [1, 2, { a: 3 }];
const copy = arr.slice();

// 证明是浅拷贝
copy[2].a = 999;
console.log(arr[2].a); // 999 (原数组的元素也被改了)
```

##### `Array.prototype.concat()`

- concat 本意是“合并”，如果不传参数或传空数组，相当于把自己和一个空数组合并，结果还是它自己（的副本）。

```js
const arr = [1, 2, { a: 3 }];
const copy = [].concat(arr);
// 或者 arr.concat()

// 证明是浅拷贝
console.log(copy[2] === arr[2]); // true (引用地址没变)
```

#### 手写

```js
function myShallowCopy(obj) {
  // 1. 处理基本类型
  if (typeof obj !== "object" || obj === null) {
    return obj;
  }
  // 2. 判断类型
  const copy = Array.isArray(obj) ? [] : {};
  // 3. 遍历
  for (const key in obj) {
    if (obj.hasOwnProperty(key)) {
      copy[key] = obj[key];
    }
  }
  return copy;
}
```

## 深拷贝

### 原理

递归地复制对象的所有层级。

- 在堆内存中开辟新的空间存放新对象。
- 修改新对象，完全不会影响原对象。

### 实现

#### JSON.parse(JSON.stringify(obj))

缺点（致命）：

- 丢失数据：无法处理 undefined、Function、Symbol（会被忽略）。
- 类型转换：Date 对象会变字符串，RegExp 会变空对象。
- 循环引用：如果对象引用了自己，会直接报错（Circular reference）。

#### structuredClone(obj) (现代标准)

这是浏览器原生支持的深拷贝 API（2022 年后各大浏览器支持较好）。

- 优点：原生支持，性能优于 JSON 方法，支持 Date、RegExp、Map、Set，且能处理循环引用。

- 缺点：不支持函数（Function）和 DOM 节点，兼容性在老旧浏览器上需要 Polyfill。

#### 第三方库 (Lodash)

使用 \_.cloneDeep(obj)。
优点：这是工业界最稳健的方案，处理了各种边界情况、循环引用、以及各种复杂的类型。

安装：`npm install lodash`

```js
// 导入
import _ from "lodash";

const original = { a: 1, b: { c: 2 } };

// 使用 Lodash 进行深拷贝
const deepCopy = _.cloneDeep(original);

deepCopy.b.c = 999;
console.log(original.b.c); // 2 (原对象不受影响)
```

#### 手写递归 (面试加分项)

```js
function myCloneDeep(target, map = new WeakMap()) {
  // 1. 基本类型直接返回
  if (target === null || typeof target !== "object") {
    return target;
  }

  // 2. 处理 Date 和 RegExp
  if (target instanceof Date) return new Date(target);
  if (target instanceof RegExp) return new RegExp(target);

  // 3. 处理循环引用
  if (map.has(target)) {
    return map.get(target); // 直接返回之前的副本
  }

  // 4. 否则，初始化副本
  // 技巧：利用 constructor 保证类型一致 (Array 或 Object 或 Map 等)
  const cloneTarget = new target.constructor();

  // 存入 Map，防止循环引用
  map.set(target, cloneTarget);

  // 5. 处理 Map
  if (target instanceof Map) {
    target.forEach((value, key) => {
      cloneTarget.set(key, myCloneDeep(value, map));
    });
    return cloneTarget;
  }

  // 6. 处理 Set
  if (target instanceof Set) {
    target.forEach((value) => {
      cloneTarget.add(myCloneDeep(value, map));
    });
    return cloneTarget;
  }

  // 7. 处理 Array 和 Object
  for (const key in target) {
    // 保证是自有属性
    if (Object.prototype.hasOwnProperty.call(target, key)) {
      cloneTarget[key] = myCloneDeep(target[key], map);
    }
  }

  return cloneTarget;
}

// --- 测试 ---
const obj = {
  num: 1,
  date: new Date(),
  reg: /a/g,
  set: new Set([1, 2]),
  map: new Map([["a", 1]]),
};
// 制造循环引用
obj.self = obj;

const cloned = myCloneDeep(obj);
console.log(cloned.self === cloned); // true
console.log(cloned.date === obj.date); // false (这是新对象)
```

### 代码详解

这道手写题考察了以下几个关键点：

1.  **循环引用 (重点)**：
    - **代码**：`map.has(target)` 与 `map.set(target, cloneTarget)`
    - **目的**：解决对象引用自己的问题（`obj.self = obj`）。
    - **原理**：使用 `WeakMap` 作为缓存。每次拷贝一个对象前，先看缓存里有没有。如果有，说明之前拷贝过（遇到循环引用了），直接返回之前创建的副本，不再递归。
    - **为什么用 WeakMap**：`WeakMap` 的键是弱引用，当目标对象不再被外部引用时，垃圾回收机制可以自动回收，防止内存泄漏。

2.  **保留原型与构造函数**：
    - **代码**：`new target.constructor()`
    - **目的**：这是一个通用的创建新对象的方法。
      - 如果 `target` 是 `Array`，`new Array()` 得到 `[]`。
      - 如果 `target` 是 `Object`，`new Object()` 得到 `{}`。
      - 如果 `target` 是 `Map`，得到 `new Map()`。
        这样可以确保拷贝后的新对象继承了原对象的原型链，且类型一致。

3.  **Map 和 Set 的处理**：
    - **目的**：Array 和 Object 可以通过 `for...in` 遍历，但 Map 和 Set 需要用 `.forEach` 遍历，并分别调用 `.set` 和 `.add` 方法来填充数据。**注意内容也需要递归深拷贝**。

简易版

```js
function myCloneDeep(target) {
  // 1. 处理基本类型
  if (typeof target !== "object" || target === null) return target;

  // 2. 判断是对象还是数组
  const clone = Array.isArray(target) ? [] : {};

  // 3. 递归复制
  for (const key in target) {
    if (target.hasOwnProperty(key)) {
      clone[key] = myCloneDeep(target[key]);
    }
  }
  return clone;
}
```
