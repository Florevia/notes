# 包装对象

## 概念

包装对象（Wrapper Objects） 是 JS 为了让基本数据类型（**String, Number, Boolean**）也能像对象一样 **调用方法和访问属性** 而设计的一种机制。

## 运作机制：自动装箱（Auto-Boxing）

当我们对一个基本类型数据（如 'hello'）调用方法（如 .toUpperCase()）时，JS 引擎会在后台进行以下隐式操作：

1. **创建**：临时创建一个对应的包装对象实例

```js
const _str = new String("hello");
```

2. **调用**：在实例上调用指定的方法或访问属性。

```js
_str.toUpperCase();
```

3. **销毁**：方法调用结束后，该实例立即被销毁。

```js
_str = undefined;
```

## 特点

1. 属性无法持久化：

   由于包装对象在调用后会被立即销毁，给基本类型添加属性是无效的。

   ```js
   let str = "abc";
   str.color = "red"; // 创建临时对象 -> 设置属性 -> 销毁临时对象
   console.log(str.color); // undefined (这里又是另一个新的临时对象)
   ```

   > new 一个包装对象，会创建一个对象，而不是基本类型，此时可以添加属性和方法

2. typeof 的区别：

   - 基本类型：`typeof 'abc' ➔ 'string'`

   - 包装对象：`typeof new String('abc') ➔ 'object'`

3. 比较时的区别：

   ```js
   const s1 = new String("abc");
   const s2 = new String("abc");
   console.log(s1 === s2); // false (引用地址不同)
   console.log(s1 === "abc"); // false (类型不同)
   ```
