# 防抖节流

## 防抖

类似于回程：只有最后一次生效

## 节流

类似于放技能：每隔一段时间才能触发一次

## 手写防抖

```js
function debounce(fn, delay) {
  let timer = null;

  // 返回一个闭包函数
  return function (...args) {
    if (timer) {
      // 如果有定时器，清空
      clearTimeout(timer);
    }

    // 重新设置定时器
    timer = setTimeout(() => {
      // / 注意：这里要绑定 this 和 参数，否则 context 会丢
      fn.apply(this, args);
    }, delay);
  };
}
```

## 手写节流

```js
function throttle(fn, delay) {
  let timer = null;

  return function (...args) {
    // 如果有定时器，直接返回
    if (timer) return;

    // 开启定时器
    timer = setTimeout(() => {
      fn.apply(this, args);
      // 执行完之后，清空定时器
      timer = null;
    }, delay);
  };
}
```
