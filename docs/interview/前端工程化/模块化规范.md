## 为什么需要模块化？

1. 全局作用域污染

   所有变量都挂在 window 上。容易变量冲突。

   > 模块化的解法： 每个模块拥有独立的作用域，变量私有化，只暴露（Export）需要公开的接口。

2. 依赖管理混乱

   以前需要手动在 HTML 里调整 `<script>` 标签的顺序。

   > 如果 plugin.js 依赖 jquery.js，你必须把 jQuery 写在前面。

   > 模块化的解法： 通过构建工具或运行时，自动解析依赖关系图，开发者只需关注当前文件需要什么。

3. 代码复用性差

   > 模块化的解法： 封装成 npm 包或独立文件，一次编写，处处引用。
