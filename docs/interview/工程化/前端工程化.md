# 前端工程化

## 概念

前端工程化是指将前端开发流程标准化、模块化、自动化，以提升开发效率、保障代码质量，并增强项目的可维护性和可扩展性。

包括以下方面：
- 模块化组件化
    - ESM、CJS、vue、react 等模块系统
- 代码规范与质量保障
  - ESLint、Prettier、Stylelint 等代码规范工具
- 构建自动化
    - Webpack、Vite、Rollup等构建工具
- 开发流程自动化
  - CICD等
- 版本管理与规范协作
  - Git、GitHub、GitLab 等版本控制工具
- 性能优化体系
  - 代码分割、Tree Shaking、懒加载等

---

## 前端工程化主要包含哪些方面？

| 方面 | 说明 | 常用工具 |
|------|------|---------|
| **构建工具** | 代码打包、编译、压缩 | Webpack、Vite、Rollup、Parcel |
| **代码规范** | 统一代码风格、质量检查 | ESLint、Prettier、Stylelint |
| **Git 工作流** | 代码提交规范、钩子 | Husky、lint-staged、commitlint |
| **测试** | 单元测试、E2E 测试 | Jest、Vitest、Cypress、Playwright |
| **CI/CD** | 自动化构建、测试、部署 | GitHub Actions、GitLab CI、Jenkins |
| **包管理** | 依赖管理 | npm、yarn、pnpm |
| **性能优化** | 代码分割、Tree Shaking、懒加载 | webpack、vite 内置 |
| **类型检查** | 类型安全 | TypeScript |
