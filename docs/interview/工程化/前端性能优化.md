# 前端性能优化

通过 **“从输入 URL 到页面渲染完成”** 的全链路视角，将其结构化为三个核心维度：

- 网络层面
- 渲染层面
- 代码/构建层面

### 1. 网络层面优化 (加载更快)

> 核心目标：**减小资源体积** 和 **减少请求次数**。

1. **HTTP 协议升级**：

- **HTTP/2**：利用**多路复用**解决浏览器并发限制（Head-of-line blocking），头部压缩减少开销。

2. **资源压缩与格式**：

- **Gzip / Brotli**：服务端开启压缩，通常能减少 60%-80% 体积。
- **图片优化**：使用 **WebP** 格式（比 PNG/JPG 小 30%），SVG 用于矢量图标。

3. **CDN (内容分发网络)**：

- 静态资源（JS/CSS/Img）全部上 CDN，利用边缘节点加速，减少主服务器压力。

4. **浏览器缓存策略**：

- **强缓存** (`Cache-Control: max-age`)：文件名带 Hash，内容不变直接读内存。
- **协商缓存** (`ETag / Last-Modified`)：用于 HTML 文件，确保及时更新。

5. **按需加载 (Lazy Load)**：

- **路由懒加载**：配合 Vue/React 的动态导入，首屏只加载核心代码。
- **图片懒加载**：`IntersectionObserver` 或原生 `loading="lazy"`，视口外的图片不加载。

### 2. 渲染层面优化 (看着更顺)

> 核心目标：**优化关键渲染路径 (CRP)**，减少阻塞和卡顿。

1. **避免阻塞**：

- CSS 放在 `<head>`，JS 放在 `<body>` 底部或使用 `defer`。

2. **减少重排重绘 (Reflow & Repaint)**：

- **批量修改 DOM**：使用 `documentFragment` 或 Vue/React 的虚拟 DOM 机制。
- **样式集中改变**：修改 `class` 而不是多次修改 `style`。
- **脱离文档流**：对复杂动画元素使用绝对定位 (`absolute`/`fixed`)。

3. **GPU 硬件加速**：

- 使用 `transform`, `opacity`, `will-change` 触发合成层（Compositor Layer），避开主线程布局计算，解决动画卡顿。

4. **SSR (服务端渲染) / SSG**：

- 对于首屏要求极高的场景（如 Next.js / Nuxt.js），直接输出 HTML，解决 SPA 白屏问题，提升 FCP (First Contentful Paint)。

### 3. 代码与构建层面 (运行更稳)

> 核心目标：**高效执行**，避免内存泄漏。

1. **算法与逻辑**：

- **长列表优化**：使用 **虚拟列表 (Virtual List)**，只渲染可视区域的 DOM（10万条数据也不卡）。
- **防抖与节流 (Debounce & Throttle)**：限制高频事件（resize, scroll, input）的触发频率。

2. **Webpack/Vite 构建优化**：

- **Tree Shaking**：利用 ES Module 静态分析，剔除无用代码。
- **SplitChunks**：提取公共代码（Vendor），防止业务代码变更导致整个 Vendor 缓存失效。
- **Scope Hoisting**：减少函数作用域包裹，减小体积。

3. **框架特定优化 (Vue 为例)**：

- `v-if` vs `v-show` 的正确选择。
- `v-for` 必须加 `key`。
- 使用 `shallowRef` (Vue 3) 或 `Object.freeze` (Vue 2) 冻结不需要响应式的大数据。
- 合理使用 `Keep-Alive` 缓存组件状态。

---

### 4. 性能指标 (加分项)

最后，我会提到如何衡量优化效果，这会让面试官觉得你很专业：

- **LCP (Largest Contentful Paint)**: 最大内容绘制时间（衡量加载速度）。
- **FID (First Input Delay)**: 首次输入延迟（衡量交互响应）。
- **CLS (Cumulative Layout Shift)**: 累计布局偏移（衡量视觉稳定性）。

**总结一句：**
性能优化是一个系统工程，我会优先解决**首屏加载**（网络+体积），其次解决**交互流畅度**（渲染+代码），最后关注**构建效率**。

## 案例2：后台管理系统列表页从 4.5s 降到 1.5s

问题：10万+ 数据虚拟滚动 + 复杂筛选。
优化：
虚拟列表（react-window / vue-virtual-scroller）只渲染可视区。
防抖 + 节流筛选输入 + 请求合并。
Tree Shaking + vite/esbuild 构建，包体 -40%。
CDN + HTTP/2 + Brotli 压缩。
骨架屏 + loading 动画提升感知速度。

效果：首屏渲染 4.5s → 1.5s，用户停留时长 +15%。
